# 五、第一个 C# 脚本

文件：`Assets/Scripts/PlayerMovement.cs`

```csharp
using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    public float speed = 5f;

    void Update()
    {
        float horizontal = Input.GetAxis("Horizontal");
        float vertical = Input.GetAxis("Vertical");

        Vector3 direction = new Vector3(horizontal, vertical, 0);

        transform.position += direction * speed * Time.deltaTime;
    }
}
```

# 六、代码解释

## MonoBehaviour

```csharp
public class PlayerMovement : MonoBehaviour
```

表示：这个脚本属于 Unity 组件，可以挂载到 GameObject。

## Update()

```csharp
void Update()
```

Unity 每帧调用。假设 60FPS，一分钟调用 3600 次。

## Input

```csharp
Input.GetAxis
```

读取输入。例如：W → vertical=1，S → vertical=-1。

## Time.deltaTime

为什么需要？

错误写法：

```csharp
position += speed;
```

不同电脑帧率不同 → 速度不同。

加入 `speed * Time.deltaTime` 后：每秒移动固定距离（与帧率无关）。

# 七、摄像机跟随

文件：`Assets/Scripts/CameraFollow.cs`

```csharp
using UnityEngine;

public class CameraFollow : MonoBehaviour
{
    public Transform target;

    void LateUpdate()
    {
        transform.position = new Vector3(
            target.position.x,
            target.position.y,
            -10
        );
    }
}
```

- 挂载到：Main Camera
- target：拖入 Player

> 为什么用 LateUpdate？保证在玩家移动之后摄像机再更新，画面不抖。
