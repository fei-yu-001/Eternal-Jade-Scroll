# 一、游戏基本信息

## 1.1 游戏名称

- 中文：十二玉楼长生经
- 英文：Twelve Jade Towers Scripture of Immortality
- 简称：TJLS

## 1.2 游戏类型

- 主要类型：2D 开放世界 RPG
- 融合：修仙、江湖、探索、经营、NPC 关系模拟、角色养成

## 1.3 核心关键词

```
命运、选择、成长、因果、长生
```

# 二、核心设计理念

## 2.1 世界不是背景，而是角色

传统游戏：玩家推动世界。
本游戏：世界拥有自己的发展。

例如玩家来到青石村：
- 如果帮助村民解决妖兽问题 → 几年后青石村发展成贸易城镇
- 如果玩家冷漠离开 → 几年后青石村可能衰败

## 2.2 玩家没有唯一正确道路

不存在"正义路线一定最好"。玩家可以：
- 成为救世侠客
- 也可以成为江湖魔头
- 也可以成为隐藏幕后势力

# 三、世界观设定

## 3.1 世界名称

九州界。

## 3.2 世界结构

```
              北荒
               |
西域 ---- 中州 ---- 东海
               |
             南疆
```

## 3.3 世界历史（四纪元）

| 纪元 | 时代 | 描述 |
|---|---|---|
| 第一纪元 | 太初时代 | 天地初开，灵气充盈，仙人遍地，十二玉楼降世 |
| 第二纪元 | 仙古时代 | 修仙文明鼎盛，无数宗门；最终仙魔大战，天地灵气衰弱 |
| 第三纪元 | 凡尘时代 | 仙人隐退，凡人成为世界主角 |
| 第四纪元 | 大劫时代 | 元末明初，天下动荡，灵气再次复苏，十二玉楼重新出现。**玩家进入的时代** |

# 四、十二玉楼设定（游戏核心）

传说：天地大道凝聚成十二座玉楼。每一座代表一种大道。获得认可者可窥长生。

| # | 楼名 | 大道 | 传承 | 能力 / 象征 |
|---|---|---|---|---|
| 1 | 太玄剑楼 | 剑 | 剑修 | 一剑破万法 / 锋芒 |
| 2 | 天机楼 | 因果 | 占卜、推演 | 窥视未来 / 智慧 |
| 3 | 长生楼 | 生命 | 医道、炼丹 | 延寿 / 生机 |
| 4 | 万象楼 | 变化 | 阵法、幻术 | 改变规则 |
| 5 | 镇魔楼 | 镇压 | 封印 | 克制邪魔 |
| 6 | 天工楼 | 创造 | 炼器、机关 | — |
| 7 | 星辰楼 | 星象 | 观天 | — |
| 8 | 幽冥楼 | 死亡 | 魂道 | — |
| 9 | 万兽楼 | 生命进化 | 御兽 | — |
| 10 | 无相楼 | 自在 | 变化自身 | — |
| 11 | 众生楼 | 人道 | 治理天下 | — |
| 12 | 归墟楼 | 终极秘密 | — | 传说：十二楼最终所在 |

# 五、玩家设定

玩家不是天命之子。开局只是普通人，区别在于：拥有探索十二玉楼的可能。

# 六、出生系统

玩家出生随机。

## 1. 家庭

| 家庭 | 特点 | 获得 |
|---|---|---|
| 农户 | 体质较好 | 农业技能 |
| 商人之家 | 经济能力 | 商业优势 |
| 武林之家 | 基础武学 | — |
| 修仙遗族 | 隐藏资质 | — |

## 2. 气运系统（五级）

| 等级 | 颜色 | 示例 |
|---|---|---|
| 普通 | 白色 | — |
| 良好 | 绿色 | — |
| 稀有 | 蓝色 | — |
| 传奇 | 紫色 | 天生剑心：剑法学习速度增加 |
| 天命 | 金色 | 玉楼残卷：随机获得十二玉楼线索 |

# 七、境界系统

## 凡人阶段

- **锻体**：强化肉身
- **练气**：吸收灵气

## 修仙阶段

- **筑基**：建立道基
- **金丹**：凝聚大道
- **元婴**：神魂强大
- **化神**：掌控天地
- **渡劫**：经历天劫
- **真仙**：超脱凡尘

# 八、功法系统

功法分级：

```
凡品 → 黄阶 → 玄阶 → 地阶 → 天阶 → 仙阶
```

示例：
- **太玄剑诀**（天阶）：提升剑类技能
- **长生诀**（仙阶）：增加寿命

# 九、门派系统

玩家可以：加入、创建、毁灭。

| 类型 | 示例 | 特点 |
|---|---|---|
| 正道门派 | 青云宗 | 秩序 |
| 江湖门派 | 武馆 | 武学 |
| 魔道势力 | — | 力量（代价：因果） |

# 十、NPC 系统详细设计（五层数据）

| 层 | 名称 | 内容 |
|---|---|---|
| 第一层 | 基础信息 | 姓名、年龄、职业、位置 |
| 第二层 | 人格 | 善良、贪婪、谨慎、勇敢 |
| 第三层 | 关系 | 好感、信任、敌意 |
| 第四层 | 记忆 | 记录玩家行为，例如"玩家曾救过我" |
| 第五层 | 人生目标 | 例如铁匠：想成为天下第一铸剑师 |

# 十一、任务系统

任务不是简单的"杀怪"。任务来源：NPC。

| 类型 | 描述 |
|---|---|
| 人情任务 | 帮助别人 |
| 探索任务 | 寻找秘密 |
| 阵营任务 | 参与势力 |
| 命运任务 | 与十二玉楼相关 |

# 十二、第一章剧情设计

**第一章：青石村**

- 玩家出生，时间：明初前夕
- 事件：村庄附近出现妖兽
- 玩家调查，发现：妖兽不是自然出现，背后有人寻找玉楼碎片
- 遇见神秘老人（守护十二玉楼秘密）
- 玩家完成考验，获得第一块玉楼残片
- 开启修仙道路

> 详细章节设计（NPC / 任务链 / 结局）见 `06_青石村章节设计.md`

# 十三、游戏核心玩法循环

```
探索 → 发现秘密 → 提升能力 → 影响世界 → 获得资源 → 继续探索
```

# 十五、设计原则

## 第一原则：系统优先

不要为了剧情牺牲系统。

## 第二原则：所有内容数据化

不要大量写死代码。

例如任务：不要写 `if 任务1`，应该读取任务配置。

## 第三原则：允许玩家创造故事
