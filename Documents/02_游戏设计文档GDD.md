# 一、游戏基本信息

## 1.1 游戏名称

- 中文：十二玉楼长生经
- 英文：Twelve Jade Towers Scripture of Immortality
- 简称：TJLS

## 1.2 游戏类型

- 主要类型：2D 开放世界 RPG
- 融合：修仙、江湖、探索、经营、NPC 关系模拟、角色养成

## 1.3 核心关键词

```
命运、选择、成长、因果、长生
```

# 二、核心设计理念

## 2.1 世界不是背景，而是角色

传统游戏：玩家推动世界。
本游戏：世界拥有自己的发展。

例如玩家来到青石镇：
- 如果帮助村民解决妖兽问题 → 几年后青石镇发展成贸易城镇
- 如果玩家冷漠离开 → 几年后青石镇可能衰败

## 2.2 玩家没有唯一正确道路

不存在"正义路线一定最好"。玩家可以：
- 成为救世侠客
- 也可以成为江湖魔头
- 也可以成为隐藏幕后势力
- 也可以在市井种田安度一生（不过会有苛捐杂税，还要服徭役，有时候妖魔横行也会破坏安宁的生活）
- 可以在乱世教学育人，创办学院，或者任教，为天地立心，为生民立命，为往圣继绝学，为万世开太平，修书卷气，浩然正气，儒释道各不相同
- 可以在落草为寇站山头农民起义做自己的势力

# 五、玩家设定

玩家不是天命之子。开局只是普通人。世界每个人都再苦苦求生，只有少数人追求12楼的究极

# 六、出生系统

出生由"**投胎问命 + 随机底盘**"两层构成。

> **铁律：随机决定命运，问答只改概率。** 答案只为命格加权（每个倾向 +3，可叠加），最终命格仍由加权随机决定。**问命是算命，不是捏人。**

## 0. 序章 · 星夜问命（投胎引导）

**前提**：问命发生在**投胎之前**——孩童不会答话，答话的是一缕前生魂魄。

### 流程

1. **星海开场**：黑屏，雾色散开。魂魄化作一点微光，悬在轮回渡口的星海之畔；守渡的老者执拂尘相候。
2. **开场白**（老者）："魂魄无前尘，心性却有痕。老朽代天问你几句话——答完，便送你入世。"
3. **六问**（脚本见下）：每答一问，虚空浮现的**命盘**上便有一道脉络逐节点亮——点亮的纹路，就是这缕魂魄的纹路。
4. **拂尘送行**：问毕，命盘纹路收拢成一点，老者**拂尘一挥**，魂光化作一缕星点，坠向人间。
5. **投胎转场**（插画）：星点穿过云层，落进万家灯火中的一盏——烛影摇动，**孩童初啼**。
6. **老者画外独白**（十二玉楼伏笔）：

   > 去吧。命是你自己称出来的分量，路，要你自己走。
   > 十二楼若与你无缘，这缕星火便散在风里；
   > 若有缘——你我，还会再见。

7. **醒来已是人间**：命格与词条揭晓，家庭落定，玩家为新生儿起名，正式开局。

老者的身份在序章不予揭示（候选设定：十二玉楼守楼人，或与玄尘同源），留待第一卷揭晓。

### 问命脚本（六问）

题面面向"一缕无前尘的魂魄"，答案照见心性。选项覆盖不同人生态度：自保平庸、游侠仗义、教书传道、济世悬壶、枭雄权谋、极致利己——魔头式答案会引来老者的叹息。

**问一 · 梦象**
> 魂入轮回前，心头浮出的最后一幅景象是——

| 选项 | 老者神态 | 暗中倾向 |
|---|---|---|
| 高楼玉宇，仙乐自云端飘下 | 老者抬眼多看了一眼："玉宇……这一缕魂，有点意思。" | 玉楼引 · 贵人候 |
| 大水漫过田庄，四处都是哭喊 | 老者皱眉："生逢乱世，这是入世的谶。" | 灾星过命 · 旧债 |
| 白茫茫什么也没有 | 老者轻笑："干净。干净得连卜算都照不出你。" | 无名 · 孤命 |

**问二 · 路见不平**
> 人间路窄。若见强梁夺人食、饿殍卧道旁，你会——

| 选项 | 老者神态 | 暗中倾向 |
|---|---|---|
| 拔刀就上，管这一趟闲事 | 老者抚掌："好一副侠骨。只盼这刀，别太快折。" | 侠骨 · 仁心命 |
| 低头快走，人各有命 | 老者微叹："乱世里活得久的，多半是低头的。" | 安乐命 · 孤命 |
| 记下强梁相貌，回头报官请赏 | 老者眯眼："借势而行，是个聪明人。" | 龙蛇命 · 文曲偏照 |
| 趁乱从死者身上摸走碎银 | 老者沉默半晌，长长叹息："乱世磨人，也磨刀啊。" | 杀星入命 · 财星照命 |

**问三 · 渡口念想**
> 轮回渡口，只许你带一样念想入世。你带——

| 选项 | 老者神态 | 暗中倾向 |
|---|---|---|
| 半块旧玉，不知是谁传给谁的 | 老者点头："信物入世，必有归处。" | 守信约 · 痴情种 |
| 一把用惯的柴刀，走到哪里都饿不死 | 老者笑："实用。" | 命硬 · 离乡命 |
| 一本破书，闲时翻上两页 | 老者整了整衣冠："书，是要传的。" | 文曲偏照 · 传灯命 |

**问四 · 信命**
> 临行前，老朽多问一句——你信命么？

| 选项 | 老者神态 | 暗中倾向 |
|---|---|---|
| 信。命里有时，终须有。 | 老者捋须："认命的人，命反而待他宽厚。" | 贵人候 · 安乐命 |
| 不信。我命由我不由天。 | 老者大笑："好！这话，多少人临死才咽回去。" | 命硬 · 杀星入命 |
| 不知道。走着瞧吧。 | 老者拊掌："着。命，就是走着瞧出来的。" | 无名 · 闲云命 |

**问五 · 若得势**
> 若有一日，你得了泼天的富贵权势——

| 选项 | 老者神态 | 暗中倾向 |
|---|---|---|
| 买田置宅，关起门过安稳日子 | 老者点头："守成也是本事，乱世里尤其。" | 安乐命 · 财星照命 |
| 开仓放粮，护一乡周全 | 老者含笑："积德之家，必有余庆。" | 仁心命 · 贵人候 |
| 设帐授徒，教书育人 | 老者起身一揖："为往圣继绝学，善。" | 传灯命 · 文曲偏照 |
| 豢养爪牙，要四方都怕我 | 老者摇头叹息："这条路走到头，连个收尸的人都没有。" | 龙蛇命 · 杀星入命 |

**问六 · 长生**
> 最后一问。长生摆在面前——你取不取？

| 选项 | 老者神态 | 暗中倾向 |
|---|---|---|
| 取。听说仙家有十二座玉楼，我想亲眼看看 | 老者目光一凝："十二楼……呵，有缘。" | 玉楼引 · 离乡命 |
| 不取。生死有命，把眼前的日子过好就行 | 老者拊掌："多少人求不来的，是你不要的。" | 闲云命 · 安乐命 |
| 若长生要负了身边人，宁可不要 | 老者动容："情之一字，最难，也最难得。" | 痴情种 · 仁心命 |
| 踏着尸骨也要取 | 老者久久无言，末了长叹："长生误人……罢了，罢了。" | 杀星入命 · 灾星过命 |

> 倾向矩阵设计约束：每条命格至少被一个答案加权；同一种人生态度（纯利己、纯平庸、纯侠义……）连续作答时，对应命格概率约三至四成——倾向明确，但从不注定。

## 3. 命格与气运的关系

- **命格是"剧本"**：决定开局事件与人物羁绊——旧债终有讨债人上门，离乡命故土留不住你，痴情种命里必有一劫。
- **气运是"稀有度"**：紫金气运附带异禀（天生剑心、玉楼残卷）。
- 两者独立掷出、允许冲突：孤命 × 天命 = 天煞孤星，矛盾即故事。
- 所谓命格只是设定如此后天还是要靠自己草莽出身也能成就霸业，命格再好若是甘于沉沦终是一事无成

# 七、境界系统

> 打磨原则：**境界是"道行"，不是"修为"。** 境界衡量的是对一条道途真意的理解深度，与灵气多寡无关。条条大路通罗马——武夫、文人、医者、商人各有各的九重天，文人也能悟道成圣。

## 0. 通用骨架：三段九重

所有道途共用同一副骨架。段与段之间是"凡与道"的分界，重与重之间靠"契机"突破（见第 3 节）。

| 段 | 重 | 含义 | 十二玉楼 |
|---|---|---|---|
| 凡俗段 | 一至三重 | 打熬己身、磨砺技艺，凡人勤学可达 | 不会注视 |
| 入道段 | 四至六重 | 触到本道"真意"，开始超凡 | 隐约有所感应 |
| 合道段 | 七至九重 | 与大道共鸣，世间顶尖 | 对应玉楼现身相邀 |

- **凡俗段人人可至**：庄稼把式练到第三重也是方圆几十里的好手；但没有功法指引，**永远迈不进入道段**——这正是普通人拼命也要走出去的理由。
- **合道段的顶点（第九重）即各道的"罗马"**：真仙、破碎虚空、成圣、长生……都是"得窥大道"的另一种说法，十二楼在尽头等着。
- 呼应第六节那条：命格只定起点，境界靠契机与苦功——草莽出身也能登顶，命格再好甘于沉沦终是一事无成。

## 1. 道途与境界命名

每条道途给九重各起一名。先定四条主道途；商、匠、艺、农等其余道途共用骨架，命名随各自章节补。

### 灵气道（修仙）——求超脱

| 段 | 境界 |
|---|---|
| 凡俗段 | 锻体 → 感气 → 炼气 |
| 入道段 | 筑基 → 金丹 → 元婴 |
| 合道段 | 化神 → 渡劫 → 真仙 |

### 武道——求不败

| 段 | 境界 |
|---|---|
| 凡俗段 | 打熬 → 明劲 → 暗劲 |
| 入道段 | 化劲 → 抱丹 → 罡气 |
| 合道段 | 先天 → 掌缘 → 生灭 |

### 文道——求传世

| 段 | 境界 |
|---|---|
| 凡俗段 | 开蒙 → 明理 → 妙笔 |
| 入道段 | 著书 → 立言 → 浩然 |
| 合道段 | 文心 → 半圣 → 成圣 |

文道特色：高境界"言出法随"——一篇文章可安一城民心，一道檄文可退一营之兵（暗合众生楼·人道）。

### 医道——求生生

| 段 | 境界 |
|---|---|
| 凡俗段 | 识药 → 诊脉 → 妙手 |
| 入道段 | 悬壶 → 回春 → 岐黄 |
| 合道段 | 生生 → 造化 → 长生 |

医道尽头与长生楼相通：第九重不叫成仙，叫"长生"——把人间的病治完，便是另一种长生。

## 2. 兼修与对照

- 主道途进境正常；兼修他道**至多凡俗段**——人的精力有限，样样通则样样松（天命气运者可多开一道）。
- 跨道途只按段位对照，不比数值：武道第九重 ≈ 真仙 ≈ 成圣 ≈ 长生。

## 3. 突破：契机，不是经验条

- 每一重的突破都需要一个**契机**：一件事、一个人、一句话、一场败仗。契机来自剧情、NPC、或玩家自主行为（打赢一场擂台、写成一篇传世文章、救回一个必死之人）。
- 契机未到，苦功堆到顶也只能停在门槛前；契机到了，一场大梦也可能连破两重。
- **入道段（第四重）是第一道天堑**：没有本道功法指引，契机永远不会来——功法从哪来，见下一节。

# 八、功法与机缘

## 1. 秘籍的稀缺

- 功法秘籍是社会资源，**天然稀缺**：普通家庭得不到，或极少得到。农家的孩子一身庄稼把式，商户的孩子满口算盘经——凡俗段到头，与入道无缘。
- 品阶沿用：

```
凡品 → 黄阶 → 玄阶 → 地阶 → 天阶 → 仙阶
```

示例：**太玄剑诀**（天阶）提升剑类技能；**长生诀**（仙阶）增加寿命。

- 流通的多为**残篇**：需收集、求教、参悟补全——机缘给一半，路要自己走完。
- 秘籍可以被抢、被骗、被借走不还，NPC 都记得（因果系统联动）。

## 2. 四条来路：家传、机缘、交换、善名

| 来路 | 条件 | 特点 |
|---|---|---|
| 家传 | 特定命格 × 家庭组合解锁（修仙遗族出身；守信约的半块玉佩；文曲偏照的族学……） | 稳、早、成体系；上限看家底，多为黄阶玄阶 |
| 机缘 | 命格作"引子"，剧情事件触发 | 险、晚、上限高；所得常是天阶仙阶残篇 |
| 交换 | 师徒恩义：门派 / 书院 / 商号 / 镖局；**宗门贡献兑换**（做门派任务攒贡献，换功法丹药）；**拍卖行竞价**（中后期随城镇篇开放） | 明码标价的路：银钱与贡献堆得出来的，多为凡品黄阶；玄阶以上要"缘" |
| 善名 | 帮村民、助好人，攒区域**声望**；声望到了自有贵人登门相赠 | 不花一分钱，但要拿一颗心换；贵人赠功法、赠丹药、指点契机 |

> **命格挂钩规则：命好者有祖荫，命薄者有天缘，心善者有贵人。** 家传线路只对特定命格 × 家庭开放；机缘线路人人可得，但引子由命格决定——文曲偏照在书院抄书容易抄出前人批注，侠骨路见不平容易救出隐修高人，杀星入命会有黑衣人深夜叩门，玉楼引独占与十二楼相关的梦中之缘。

### 声望与贵人相助

- **声望是区域性的**：青石镇的好名声，出了村就重新算——每个聚落有自己的舆论圈。
- **声望不是刷出来的，是 NPC 记忆的汇总**（联动 NPC 五层数据·记忆层）：替铁匠修炉、替药农追贼、灾年放粮，一件件小事攒出来。坏事同样攒：恶名高自有魔道来招揽、仇家来寻仇——条条大路通罗马，也包括罗马的另一面。
- **贵人相助**：区域声望过门槛后触发——退隐老前辈、路过的行商、云游的郎中主动登门，赠功法、赠丹药，或直接指点一个**突破契机**（与七节"契机"机制挂钩）。
- **贵人候命格**：声望门槛更低、贵人来得更早更多——"命里必有贵人相助"，这条命格就是善名线路的加成。
- 贵人赠物是**人情不是买卖**：收了礼要还，NPC 都记得（因果系统联动）；声望崩了，贵人也会寒心离去。

## 3. 机缘与贵人示例表

| 引子 | 场景 | 机缘 | 所得 |
|---|---|---|---|
| 无（任何命格） | 采药坠崖 | 崖底枯骨旁有一方遗蜕 | 玄阶残篇 + 未了遗愿（后续任务） |
| 无（任何命格） | 荒野夜路 | 助黑衣人击退追兵，分文不取 | 黑衣人留下一枚玉牌，凭牌可取一物 |
| 无（任何命格） | 茶棚听书 | 说书老人散场后叫住你，赠书一部 | 天阶残篇；说书人身份成谜（与序章守渡老者是否同源，留白） |
| 无（任何命格） | 河里游玩 | 摸鱼摸到一只沉水铁盒 | 铁盒锈死，需寻匠人开启（跨道途合作） |
| 无（任何命格） | 帮村民解决妖兽之患 | 区域声望过门槛，退隐老前辈登门致谢 | 玄阶功法 + 一句契机指点 |
| 侠骨 | 路见不平 | 救下的老镖师原是武道隐修 | 武道入道段功法 |
| 文曲偏照 | 书院抄书 | 抄本页边有前人批注，凑齐可成篇 | 文道功法残篇 |
| 杀星入命 | 黑市 | 黑衣人以秘籍抵债 | 天阶魔功（有反噬，善恶线分岔） |
| 玉楼引 | 梦中 | 梦入玉楼一角，醒来掌心有字 | 十二楼线索 + 灵气道残篇 |

- 机缘稀有且不可复读：同类机缘一次性或长冷却，杜绝刷。
- 机缘优先挂在**探索、社交、善恶行为**上——鼓励玩家出门、跟 NPC 打交道、做出选择，这是开放世界的核心奖励回路。

## 4. 后续扩展

- 每条命格逐条设计"专属机缘链"：一条命格 = 一串跨章节小故事（归入任务系统设计）。
- 各道途高重境界的"契机事件"清单，随对应章节设计补充。

# 九、门派系统

玩家可以：**加入、创建、毁灭**——也可以一辈子无门无派当散修，看宗门起高楼、宴宾客、楼塌了。

## 1. 门派类型

| 类型 | 示例 | 特点 |
|---|---|---|
| 正道门派 | 青云宗 | 秩序 |
| 江湖门派 | 武馆 | 武学 |
| 魔道势力 | — | 力量（代价：因果） |

宗门同样套用 NPC 五层数据：一门之派也有人格、关系、记忆与"人生目标"——青云宗想重整正道，魔道想的是另一件事。

## 2. 门派之间：结盟与结怨

- 门派之间有关系网：**同盟、世仇、依附、中立**，随事件演变——弟子冲突、秘境相争、大会结怨、联姻通好。
- 关系落到玩家头上：同盟门派对你客气三分，世仇门派见你绕着走，或直接动手。
- 玩家可以搅动这滩水：递刀、传信、做说客、当替罪羊——挑动两宗相争是枭雄线（龙蛇命）的经典玩法。
- 门派关系由世界模拟推进，**不围着玩家转**：玩家不出手，两宗也会自己结盟、自己翻脸（呼应 2.1"世界拥有自己的发展"）。

## 3. 宗门大选

- **收徒大选**：数年一度，各大宗门开山门选徒——测灵根、试心性、比武艺，各宗各有各的考法。无门无派者入宗的正途；落选也有分支剧情——看中你的未必是宗门，可能是观礼席上的散修高人（接八节善名线路）。
- **传承之争**：大选也指宗门内部掌门换代——候选长老各领一系弟子相争。玩家若在宗门中，站队就是站未来，押对了青云直上，押错了……也可以叛出师门。
- 命格挂钩：文曲偏照易被书院系看中，侠骨在擂台最出彩，杀星入命会被魔道宗门的"选徒"注意到。

## 4. 修仙大会：天骄争锋

- 定期盛会，修仙界的武林大会：各宗门年轻一代同台比斗，夺魁争的是**机缘**——秘境名额、天材地宝、孤本功法的传抄权。
- 散修也可报名，只是没有宗门资源托底：赢了寸功，输了伤身。
- 大会是**契机的高发地**（七节）：一场败仗、一句点拨、一位伯乐，都可能在这里等着一重突破。
- 夺魁即名动一方：声望大涨（善名线），但也会被落败宗门记恨——因果双向记账。

## 5. 联宗探秘

- 秘境（长生天、云梦泽、娑婆州、苍梧野……见 3.2 世界结构）凶险，单宗难吞，常见数宗**联合探索**：名额怎么分、队伍怎么编、收获怎么账，全是博弈。
- 玩家的位置可以是本宗代表、散修雇佣、向导——或者在暗处等他们两败俱伤的人。
- 秘境产出与八节机缘表打通；归墟相关线索，只在最深的联宗探秘里出现。

## 6. 创建宗门（建造线）

财富、声望、境界三者达标，解锁"开山立派"：

| 条件 | 门槛（初版数值，待调） |
|---|---|
| 境界 | 任意道途入道段（第四重）以上 |
| 声望 | 一处聚落的顶格声望，或江湖扬名（如修仙大会夺魁） |
| 财富 | 置得起一座山头：宅产、银钱、护山大阵的启动资金 |

- 建造玩法：选址、立山门、建殿堂（传功堂 / 炼丹房 / 器库……各给不同加成）、布护山大阵、张榜收徒。
- 弟子是活人：套 NPC 五层数据，各有来历与目标；会出门游历，会给你惹事，也会给你长脸。
- 你的宗门从此进入门派动态：有人来结盟，有人来结怨，修仙大会与联宗探秘都有你一张请帖。
- 魔道同样可以开宗立派——只是招来的弟子、登门的"客人"，味道不太一样。

# 十、NPC 系统详细设计（五层数据）

## 1. 五层数据

| 层 | 名称 | 内容 |
|---|---|---|
| 第一层 | 基础信息 | 姓名、年龄、职业、位置 |
| 第二层 | 人格 | 善良、贪婪、谨慎、勇敢 |
| 第三层 | 关系 | 好感、信任、敌意 |
| 第四层 | 记忆 | 记录玩家行为，例如"玩家曾救过我" |
| 第五层 | 人生目标 | 例如铁匠：想成为天下第一铸剑师 |

> 补充：人格分**表层**与**里层**——表层是人前的样子，里层是底牌。好人坏人，不在脸上（见第 3 节）。

## 2. 对话与托付：帮人解决问题

- NPC 按自己的作息生活（铁匠上午打铁、下午卖装备），对话要看时辰和场合。
- 话题由五层数据驱动：人格定口吻，关系定态度，记忆定他会主动提什么（"上回多亏你……"）。
- 每个 NPC 手上都有一份**难处清单**：修炉、找牛、赎当、抓药、讨薪……玩家出手解决，该 NPC 的好感与信任上涨，聚落**声望**上涨（走八节善名线），也是日后**贵人相助**的铺垫。
- 解决方式多样：出力、出钱、出主意、动武——NPC 记得你**怎么**帮的（因果系统联动）。

## 3. 好人与坏人：善恶不在脸上

- 大多数 NPC 是讨生活的普通人，但也有坏的：缺斤短两的奸商、放印子钱的泼皮、卖假药的游方郎中，乃至谋财害命的"老实人"。
- 坏人的恶行是**世界模拟的一部分**，不是贴给玩家看的任务标签：奸商会真掺假、真抬价、真害人，受害者是其他 NPC——他们的难处清单里会出现"病越来越重""货款收不回"。
- 表里人格分离：表层决定日常对话，里层决定私下勾当。里层底牌，只能靠线索揭开。

## 4. 线索与打听：话赶话问出真相

- **线索靠嘴问**：茶棚闲话、酒后真言、货郎的见闻、孩子的目击、老人的旧账——和其他 NPC 对话，是探案的第一手段。
- 线索是**结构化数据**（谁、何时、何地、何事），可拼接印证：三条对上，真相自明。
- 打听有门槛：交情浅的打官腔，要请酒、送礼或帮过忙才掏心窝（关系层联动）；词条"爱打听"在这条线上是实打实的加成。
- 证人会说谎：坏 NPC 会买通人口、散布假线索——玩家需要交叉验证，甚至当面**对质**。
- 真相大白后的选择各有代价：**报官**（声望上涨，因果清白）、**当众揭穿**（声望大涨，但结下死仇）、**私下分赃**（得财得恶名，还可能被知情人拿住把柄）、**放长线**（枭雄线，把把柄攥成线）。

### 示例：青石镇"药案"

- 表象：杂货铺王掌柜和气生财，年年赞助社戏。
- 异象：张郎中的病人接连加重；货郎老李嘀咕，王掌柜最近进了一批便宜得反常的"药材"。
- 打听：药童（账目对不上）→ 醉汉（见过半夜搬货）→ 病人家属（症状）。
- 拼图：王掌柜往药材里掺铅粉压秤，病人是被他害的。
- 处置：报官 / 揭穿 / 分赃 / 隐忍——四条路，四种声望与因果。

## 5. 财不外露：财富是饵，也是靶

- **财气会暴露**：身上金银越多、出手越阔绰，全城的眼睛越亮——穿金戴银招摇过市、当众豪掷，都是在给贼递信号。
- **被盯上是世界模拟，不是随机刷怪**：泼皮盯钱包，惯匪盯行商，杀手盯豪客；对方会踩点、跟踪、等你最弱的时候动手——劫道、下药、夜里翻窗、雇人绑票，各有各的章法。
- **应对的路子**：
  - 藏——粗布衣裳、碎银分装、大额走银票；把钱存进商号钱庄（商号也会倒，门派动态联动）；
  - 镇——境界、随从、住镖局，贼也会掂量；
  - 问——交情好的 NPC 会提点一句"最近城里来了生面孔"（关系与线索系统联动）。
- **反用：螳螂捕蝉，黄雀在后**——露富是可以钓的饵：故意露富走夜路，等劫匪扑上来一网打尽；顺着赃物追销赃的黑市、山寨，甚至揪出分账的"体面人"（接线索系统与任务链）。也可以反过来雇贼做局，把仇家引到必经之路——恶线玩法，因果记账。
- **命格联动**：财星照命赚得快、招贼也快，得学着藏；杀星入命则通常站螳螂那一头。
- 平衡原则：抢劫暗杀不是惩罚，是**财富的风险价格**——藏得住是本事，露得起是胆气，钓得上是手段。

## 6. 远期：AI 驱动对话（阶段六）

- 本地小模型（Qwen）驱动 NPC 自由对话是长期特色；**记忆、难处清单、线索全部数据化**（第二原则），将来 AI 只是给这套数据换一张更活的嘴——结构不变，剧情不崩。

# 十一、任务系统

任务不是简单的"杀怪"。任务来源：NPC 与**悬赏牌**。

| 类型 | 描述 |
|---|---|
| 人情任务 | 帮助别人 |
| 探索任务 | 寻找秘密 |
| 阵营任务 | 参与势力 |
| 命运任务 | 与十二玉楼相关 |
| 悬赏任务 | 悬赏牌接取，见下节 |

## 1. 悬赏牌：每个聚落一块

- 村口、城门、商会墙上，各挂一块悬赏牌。任务来源五花八门：官府缉凶、商会护货、乡老寻牛，以及……不愿露面的雇主。
- **两种接法，两种活法**：

| | 匿名接 | 真名接 |
|---|---|---|
| 做法 | 斗笠草鞋，画押画圈 | 画押留名 |
| 好处 | 查无此人——脏活、被仇家盯着时、想低调时都走这条 | 事成传遍全城，**名望上涨**（八节善名线），后续贵人相助的铺垫 |
| 代价 | 声望不涨，事后也接不上雇主那条线 | 行踪、本事、价码全摆在明面上——**会被人利用算计** |

- **真名的风险是写进系统的**：有人雇你是借刀，有人算准你会去某处而设局，有人专挑你接了悬赏、离村在外的空档动手（呼应十节"财不外露"——赏金在手更招眼）。
- 悬赏牌本身是活的：好任务被别的冒险者抢走；有引人送死的**假悬赏**；也有官府缉拿罪犯的悬赏——接不接、抓活的还是杀人领赏，善恶记账。
- 名望联动：有名声的人真名接单有溢价（信任价），无名小卒只能匿名攒履历——名望本身是一种资产。

# 十二、秘境副本与战斗

## 1. 小秘境：定期开启的轮转副本

- 每个村镇近郊都有一处**小秘境**：灵气汇聚的洞窟、古战场遗迹、瘴气山坳……**定期开启**（朔望之夜、雨季之后），开时灵物生长、妖兽活跃。
- 开启期的三件套：
  - **猎妖**——击杀妖兽取材料（皮、骨、内丹），走炼器炼丹的经济；
  - **采药**——灵草只在开启期结果，抢的是时机；采药 NPC 也在抢，会遇到同行，也会起冲突；
  - **探遗迹**——宝箱、机关、遗骨遗篇，是八节机缘系统的"日常小口径"。
- 定期重置：妖兽再繁衍、灵草再生长、机关重合；小秘境深处偶有裂缝，通向**大秘境**（长生天、归墟那一级）——小秘境是练手补给，大秘境是九节联宗探秘的玩命场。
- 副本不与世界割裂：妖兽潮、采药人的竞争、遗迹里死过的人，都会在村镇闲话里留下痕迹（十节线索系统）。

## 2. 战斗：走位为先的 2D 动作

定位：**类地下城的 2D 动作战斗**——打斗场景是本作玩法的骨架，按"读起手、走位、抓硬直"的节奏设计。

- **走位是第一防御**：妖兽与敌人都有一眼可读的起手动作和判定范围（圆形、扇形、直线冲撞），站位、绕背、卡地形是基本功。
- **闪避**：翻滚 / 疾步，带无敌帧，受精力条约束；**完美闪避**触发短暂时间凝滞与反击窗口——"见切"是高手的分水岭。
- **跳跃**：跳过地面波动、躲横扫、上高台居高临下；空中可接下劈打断。
- **普攻与技能**：普攻轻击连段攒气，技能耗气挂冷却——**技能组由功法决定**：剑诀出剑气、拳掌出贴身爆发、医道给自己吊气回血、文道高境界"言出法随"直接改写战场规则。你学的功法，就是你的技能表（与七、八节打通）。
- **境界不是数值碾压**：高境界出手更快、精力更长、招式更多变，但走位得当，散修照样能磨死天骄——"以下克上"在玩法上必须成立。
- **妖兽有部位**：断角、破甲、伤腿各有判定，部位破坏影响材料掉落——猎妖与战斗收益挂钩。
- **死亡的代价**：掉部分随身银两、被 NPC 抬回村养伤耗掉时日——顺带全 村闲话"听说那位昨晚在洞窟里被拱出来了"（声望的另一种记账）。
- 手感目标：起手清晰、判定诚实、受击有反馈——修仙不是无脑割草，每一刀都要落对地方。

# 十三、第一章剧情设计

**第一章：青石镇——成人即乱世**

## 0. 命格定家：命格落成一个家

- 十九种命格不是空批语，各自落地为**一种开局家庭**：都是青石镇人，但家不一样——守信约是留着半块玉佩的贫农之家，文曲偏照寄养在村塾先生家，财星照命生在货郎之家，玉楼引/离乡命与修仙遗族、行脚医家相互牵引……
- **0–18 岁不交给玩家**：童年由命格与词条驱动几段插叙小场景（摔断腿的爹、教认字的先生、河里捞起的沉木盒），替玩家把"来路"讲完，快进可跳。
- **18 岁成人礼（加冠 / 及笄），玩家接手**：自由从这里开始，黑暗也从这里开始。

## 1. 时代第一课：黑暗与不公

玩家接手的第一天，学的不是战斗，是**活着**。元末明初的世道要用身体感受：

- 里正上门催徭役，爹被抓去修河堤；收税官量田，大斗进小斗出；
- 流民队伍过村，村人闭户不出；隔壁村的少年被拉了壮丁，一去不回。

**生活的追求与目标**由此而来：攒钱赎回徭役、给爹抓药、买一头牛、学一门手艺——普通人的愿望越小，时代压垮它就越容易。这是玩家一切动机的根。

## 2. 力量格局：练气即仙人

- 此世灵气刚复苏，**十二玉楼只是老人们吓小孩的传说，没人信**。
- 全村乃至全县仰视的最强者，是那位云游至此的老道——**练气几层而已**，村民已称之为"仙师"，见之欲拜。
- 用七节的标尺说：**凡俗段第三重（炼气）在凡人眼里就是仙**——九重天梯，村里人连第一重都看不见。玩家此刻连一重都没入门。
- 这条标尺一方面压出天花板之高，另一方面为"仙人也死"的冲击埋引线。

## 3. 探索村庄：生活与伏笔

接手后的第一个开放阶段：青石镇 + 近郊（含小秘境）自由探索。

- **生活追求**：做悬赏、帮 NPC 解决难处攒声望、学一门凡俗手艺（凡俗段一至三重）、攒钱置办家业——主线不催，日子自己过。
- **十二楼的伏笔以"传说"形态散落**：村塾先生讲的古、茶棚说书人的段子、后山破庙剥落的壁画——没人当真，玩家也只当故事听。

## 4. 主线三幕

### 第一幕 · 乱世学步（18 岁 → 入门）

1. **妖兽袭村**（雨季之后，与小秘境开启同律）：牲畜被杀，村民恐慌——第一场战斗教学（走位、闪避）。
2. **调查**：妖兽不是野生的——颈上有铭牌，伤口是法器所伤，**背后有人在摸玉楼信物的下落**。
3. **神秘老人现身**：危局中出手救村，深不可测；玩家认出他像谁——序章守渡的老者。他不施舍、不收徒，只留一句批语就走，修行之门未开。
4. **辨引路人**：镇上各色人等里，藏着一个肯引你入道的好人——**这个判断不靠主观好感，靠十节线索系统**：谁的话和时间线对得上、谁在夜里烧不该烧的纸、谁救人时先看四周……草蛇灰线，早在他登场之前就埋进探村日常。错把坏人当引路人，是要还的。
5. **入门**：引路人领你进凡俗段。同一段日子里的另一课：乱世里救助不相干之人，可能被感激，也可能被**落井下石**——伸不伸手，玩家自己掂量，因果都记账。
6. **仙人之死**（暗线）：村中供奉的练气"仙师"死于妖兽余波——"仙人也会死"敲碎村民的世界观，也敲给玩家：传说，不只是传说。

### 第二幕 · 神算惊变（离开青石镇前才开启）

1. **中州神算子算天命**：算出青石镇下压着一处千年难遇的遗迹——**仙魔大战时一位谪仙人的葬身之地**。青石镇的原貌，由此翻出底牌。
2. **高手云集**：宗门、世家、江湖客、黑道闻风而动——村人只见"仙人过境"，玩家第一次亲眼看见入道段的世界有多高。
3. **站位按命格**：命格好、有靠山的玩家可入局争抢机缘；命格差的无名之辈只能在夹缝里看——**并在这里见证亲人离世，人命如草芥**。
4. **破遗迹**：遗迹有境界门槛（不到破不开）、有谜题与机关，深处坐着**仙人残魂**——千年不散，实力早已衰弱；这是玩家第一场"以下克上"的 boss 战。引路人在乱局中或显露真身、或挡在你身前——分支不定死。
5. **机缘被夺与信物流向**：遗蜕功法等大头终被有势力之人抢走；装着**仙人信物**的宝盒被黑衣人抢出，途中遭正道阻拦——宝盒滑落，石头**偷梁换柱**，黑衣人带着假货遁走而不自知。玩家能否拿到信物按命格两分：**命格好、有靠山**者大概率正面夺得机缘与仙人信物；**命格差、无依无靠**者只带走恨与疑问——至少他是这么以为的（信物其实已在怀中，见第 6 节）。
6. **代价与离镇**：镇子的底细已经泄露，各方都不会放过这口井——留下来是等死。**离开青石镇**，第一章完。

## 5. 章末状态

- 玩家手里有：一件**玉楼信物**或它的线索（十二楼各有一件信物——此物所属之楼是第一章最大悬念，可留到江湖篇揭晓）、凡俗段底子、村庄声望、几个伙伴与一个（或一群）仇家。
- 身后有：一座回不去也忘不掉的青石镇——它因玩家的所作所为走向兴旺或衰败（2.1 的承诺，第一章就兑现）。
- 留给后续章节的灰线：引路人的真身、谪仙人的来历、抢走机缘的势力、坠崖生死不明的石头（见第 6 节）。

## 6. 同乡好友：石头（示例名，核心羁绊 NPC）

主角的镜像：同一片土生土长，却走了一条玩家最不屑的路——**妥协**。他的弧光贯穿第一章，尾巴伸进江湖篇。

### 第一幕 · 同行

- 一起长大，探村、妖兽之夜、做悬赏都同行（合作点位：一个引开一个摸线索——给战斗与探案加双人桥）。
- 他的愿望朴素到卑微："让乡亲们吃饱饭。"

### 第二幕 · 分道（挂"神算惊变"）

- 遗迹开启、各方入镇，两人第一次吵翻：主角要争，石头要忍——**分开**。
- 石头"投了"主角所不齿的夺宝势力。**真相：以投名状换乡亲平安、换主角不被清算的妥协。**
- 他对主角刻意冰冷——演给监视者看的，两人内心都难受。冰冷里只留一处破绽：无人处攥紧的拳头、塞进干粮的那块肉干——一周目读作背叛，二周目全是心疼（灰线设计）。
- **黑衣人毁约屠戮乡亲**：主角反抗，被打得半死——石头以"处置"为名喂下**假死丹**（从势力里偷的，这个细节本身也是灰线），背回一条命。
- **信物贴身**：喂丹的同时，石头把偷梁换柱得来的**真信物装进竹筒，塞进主角衣服里**。主角从假死中醒来，只当自己大难不死、好友已叛——要等相认时以石头视角闪回，才知道命是他给的，信物也是。
- **背刺与坠崖**：石头随即背刺黑衣人，事败，重伤被丢下悬崖。

### 伏笔 · 相认（江湖篇开场）

- 石头没死：**失忆**，顺流而下被好心人救起。
- 主角走出青石镇、开启新篇章时触发唤起剧情——记忆回来，真相大白，相认重归于好。
- 相认戏的钩子是复盘：十节线索系统是结构化数据，玩家可以回看第一章每一条线索——"原来那时候，他就已经……"

### 系统挂点

- 假死丹归八节丹药体系（稀有品，来路本身是一条可追的线索）。
- 关系层特殊处理：分道后石头对主角的关系走**暗线**（表面敌意、实际守护），NPC 记忆层照常记录他的真实行为——复盘时对得上。
- 相认剧情按命格调浓淡：痴情种、守信约加重情义戏。

## 7. 青石镇任务安排：主线链与支线网

### 主线任务链（串三幕，一步一个成长台阶）

| # | 任务 | 玩法内容 | 成长所得 |
|---|---|---|---|
| 1 | 税与役 | 接手第一天应付里正催役：交钱 / 找人 / 顶替，三选一 | 定下经济基调与善恶起点；乡老指路，解锁悬赏牌 |
| 2 | 夜里的兽吼 | 妖兽袭村，战斗教学，与石头同行 | 凡俗段入门资格；悬赏牌出现"妖患单" |
| 3 | 兽之来历 | 调查妖兽（问药童、货郎、猎户——线索系统教学） | 法器伤情报；神秘老人的一句批语 |
| 4 | 谁是引路人 | 三名候选人各有破绽，靠线索辨真伪——选错有代价但不致命 | 引路人确认，凡俗段第一重 |
| 5 | 镇上的一天 | 自由成长期：学手艺、做悬赏、小秘境练手（支线全开放） | 修到破遗迹的境界门槛 |
| 6 | 神算惊变 | 中州神算子到镇，遗迹开启 | 第二幕大戏 |
| 7 | 离镇 | 假死醒来、竹筒信物、告别青石镇 | 章末状态，第一章完 |

### 支线任务网（按"身、技、心、情"四类排布）

**身（战斗 / 境界）**
- **镇口擂台**：武馆每月擂台，打到头拿武道凡俗功法（交换线·恩义）。
- **小秘境·猎妖令**：悬赏牌定期刷猎妖单，材料换钱换丹——战斗熟练度养成场。
- **药田守夜**：帮药农驱兽（双人桥，可与石头配合），得医道启蒙书。

**技（手艺 / 经营）**
- **铁匠的炉子**：难处清单首单，修炉学锻造入门——铁匠成为终身恩义人（贵人铺垫）。
- **货郎的账**：帮货郎盘账识假银——财商开蒙，认下全镇商号（拍卖线伏笔）。

**心（声望 / 因果）**
- **药案**：十节示例做成正式支线，报官 / 揭穿 / 分赃 / 隐忍四处置——第一次触碰"真相的代价"。
- **落井之石**：救助被讹的外乡货郎，可能被反咬——坚持到底有善名回报（呼应"救助可能被落井下石"）。
- **说书人的茶钱**：给说书老人捧场，他讲的每个故事都藏着十二楼传说碎片——集齐有奖（伏笔收集类）。

**情（伙伴 / 羁绊）**
- **石头的愿望**：和石头一起攒钱给孤寡老人修屋顶，立约"以后让乡亲们吃饱饭"——分道前的情感铺垫，相认戏的钩子。
- **先生的古**：帮村塾先生抄书听故事——文道启蒙 + 十二楼传说收集。

### 排布原则

- **每条支线教一个系统**：悬赏牌、难处清单、线索、秘境、功法来路——支线即新手教程，只是长着一张任务的脸。
- **支线不锁主线，但章末见差距**：声望低，遗迹里没人替你挡刀；钱少，买不起护身丹药——世界按你长成的样子给你难度。
- **命格改变支线的味道**：同一条"货郎的账"，财星照命能砍出更好的价；"镇口擂台"上侠骨有人捧场、杀星入命有人寻衅。
