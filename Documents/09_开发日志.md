## 2026-09-28（开发 · M2 行囊 + 配置外置 + M1 收尾）

### 做了什么

1. **配置全部外置，代码里不再留副本**：新增 Core 层 `Json`（自写的小型 JSON 读取器——Unity 的 `JsonUtility` 在测试进程里不可用、`System.Text.Json` 在 Unity 里不可用，与其引依赖不如自己读；报错带字符位置）、`ItemTable`（品阶/类别/堆叠/基准价/图标/批语式描述）、`TownMap`（走廊、立绘、地标、出生点、透视上下限）。正式数据落在 `Resources/Config/items.json`（18 件）与 `town-map.json`。`FrontEndMap.cs` 从内联常量改为读表，读不到就不放行——不再出现"代码里的地图"与"画上的地图"两套数据。
2. **存档 v3**：新增 `coins`、`localReputation`、`bag`（24 格 `ItemStack[]`）。旧档在读取处迁移——v1/v2 存档进内存即补上开局行囊与盘缠，写回按当前 schema 落盘，未来版本保护不变。新档一落地就带"干粮×5、金疮药×2、柴刀、粗布袍、三百文"（开局清单写在物品表里，调开局不用改 UI）。
3. **行囊规则 `InventoryRules`**：按表堆叠、放入（先补同类再占空格）、取出、换位（同类合并、异类交换）、整理（按物品表顺序左对齐）、校验。纯逻辑、无 Unity 依赖。
4. **声望折扣 `Reputation`**：地方声望每 20 点一档、每档让利 3%、上限 15%；买价向上取整、卖价向下取整，绝不算到 0。M3 交易所直接复用同一套。
5. **M2 行囊界面**：24 格宣纸格（6×4）、类别页签（全部/丹药/吃食/材料/器用/兵器/任务物，全部来自物品表的 `categories`）、悬停 150ms 延迟浮签（品阶色标题 + 批语 + 类别/数量/市价）、左键选中、拖拽换位、双击使用、整理、铜钱与声望摘要。入口：城镇页「行囊」按钮与 `B` 键，预览页也加了「行囊」。
6. **M1 收尾**：脚步尘点（八枚循环的淡墨点、0.4s 淡出、跑动更大更浓）、转向缓冲（80ms 挤压过渡代替硬翻面）、步频与速度联动（`PuppetActor.SetStepScale`）、`SetMotion` 同值不再重置相位、小地图金点加墨边 + 朱红地标点、点舆图展开全图浮层（本卷全图 + 地标名 + 图例，章内不做传送）。
7. **验收扩到 9 页 + 行囊断言**：`FrontEndShot` 新增 inventory 页与 `VerifyInventory`（24 格、浮签显隐、拖拽往返、使用同类消耗、任务物不可用、整理落盘、schema 与堆叠上限）；`Tools/SaveChecks` 新增 `ConfigChecks` / `InventoryChecks`，直接读工程里的正式 JSON，改坏了先在测试里报警——断言从 41 项增到 107 项。

### 问题与解决

| 问题 | 解决 |
|---|---|
| 读取配置处处判空（缺字段返回 null，一路 NullReference） | `JsonValue` 增加 `Missing` 单例：缺字段与 null 都读成它，读配置的代码只需判一次 `IsNull` |
| 立绘枢轴取顶边，配置里的坐标其实是地平线——立绘整体下挂一个身位，遮挡关系也跟着错 | 立绘与纸偶的枢轴一律取底边中点（`pivot.y = 0`）：坐标即脚底，纵深排序才是"谁站在谁前面" |
| 尘点层排在人物之上会糊住脚 | 纵深排序时给尘点层留一位（`slot + 1`），人物永远压在尘点之上 |
| `PuppetActor.SetMotion` 每帧被同值调用，动画相位被反复清零 | 同值直接返回；表现是"走路时腿不摆"，只有真跑起来才看得见 |
| 行囊摘要一行塞了七个数字，换行后压住「整理」按钮 | 拆成两行（铜钱/声望一行、卷数/格数一行）并各自限宽，按钮挪到右侧留白 |
| 洪水填充校验走廊连通时，只在一个角上相碰的两条走廊被算作连通 | 改为要求交集至少有一条边的宽度（角碰不算），那里根本没有可穿过的缝 |
| `SaveChecks` 的 v2/v3 断言写死了版本号，存档一升级就连环失败 | 断言改读 `SaveData.CurrentSchemaVersion`；"未来版本"用例改为当前版本 + 1 |

### 验收结果

- `dotnet build Tools/UnityCompileChecks`：0 错误 0 警告；`dotnet run --project Tools/SaveChecks`：**107 项全部通过**（含配置表 40 项）。
