## 0. 这段过场是什么

大纲序章原文（第 5–7 步）：

> 星点穿过云层，落进万家灯火中的一盏——烛影摇动，孩童初啼。
> 老者画外独白：去吧。命是你自己称出来的分量……
> 醒来已是人间。

**起止边界（本文口径）**：从"拂尘一挥、命盘收拢成一点"起，到"屋内烛影摇定、一声初啼"止。
之后立刻切"醒来已是人间"标题卡，进入命格与词条揭晓、为新生儿起名。**过场不承载任何玩法选择**，六问全部在此之前已完成。

选它的理由（沿用已采纳结论）：不需要主角露脸；画面只有星、云、灯、窗、烛；不涉及任何角色长相、服饰、年龄设定，身份漂移风险接近零；不改故事设定一个字。

| 项 | 锚点 |

## 3. B. 每镜能不能不靠视频生成（最重要的一列）

判定标准：这段镜头的成败取决于**光与雾的运动连续性**，还是取决于**画面里有多少具体信息**。
信息多、要认得出是"一个镇子、一片屋脊"的，靠生成/手绘；只靠氛围与光变化的，Unity 内做就够八成。

| 镜头 | 判定 | 依据 |
|---|---|---|
| 星点坠落、拖尾 | Unity 内做 | 一个 sprite + alpha 拖尾 + 曲线插值，效果与生成的差别肉眼几乎看不出；生成反而会给它加上不该有的镜头抖动 |
| 云层流动、穿云 | Unity 内做 | 三层不同速度的雾贴图，MenuAmbience 已证明可跑；生成过的云还会在循环处跳帧 |
| 灯火闪烁 | Unity 内做 | 十几个小光斑按不同频率做 alpha 呼吸即可。生成视频里的灯火往往被统一节奏，反而假 |
| 烛火摆动 | Unity 内做 | 3 帧抖动 + 光晕缩放，够用。真做 4K 烛火视频是浪费 |
| 淡入淡出、白场、标题卡 | Unity 内做 | 本就是 UI 层的事，生成只会多一层压制 |
| 镜头缓推/横移 | Unity 内做 | 对静态图做 UV 缩放/平移。**前提是静帧分辨率足够**（建议 2 倍目标分辨率出图，留裁切余量） |
| 尘埃、飞絮 | Unity 内做 | 与现有 16 个浮尘同一套实现，可调数量做低配档 |
| **镇子全景（S3 / F4）** | **必须新产出静帧** | 屋脊疏密、巷道走向、灯火分布构成"这是一个人住的地方"的信息量，程序素材堆不出可信轮廓 |
| **窗内烛影（S4 / F6）** | 需要一张静帧，但不需视频 | 窗格与纸的质感靠一张图即可；运动部分（烛焰、手影）由程序补 |
| 老者拂尘动作 | 不做动画，只做剪影位移 | 一帧剪影 + 轻微位移 + 拂尘末端 2 帧抖动。他的身份要留到卷一才揭晓，动多了容易被认出 |
| 初啼与母亲抱婴 | 不上镜 | 只给窗纸手影。任何"人形"都可能被读成角色设定，这是本段最大的身份风险点 |

**一句话结论**：这段过场**没有任何一镜需要视频模型**。它需要的是 3 张静帧（镇景、窗景、命盘/剪影）+ 一套已经存在于项目里的程序层。视频生成的候选位置只有 F3 穿云（纯雾，最容易做也最没必要），以及未来若要把短版压成单文件播放时的整体成片。

**这条结论对预算的意义**：首段过场的钱应该花在**1 张镇景静帧**上，不是花在 5 秒视频上。视频留给真正需要"连续动作与镜头调度"的段落（例如未来卷一妖兽袭村的 8–12 秒冲突段）。

## 4. C. 触发与工程契约（供青衡审）

| 项 | 建议 | 依据/风险 |
|---|---|---|
| 触发点 | 六问结束、命格揭晓之前，由章节配置里的显式事件触发（`prologue.rebirth`） | 架构文档 §四 明确禁止在 `Awake` 或启动菜单自动播 |
| 是否首次才播 | 首次必播；`Skipped` 也算看过，之后默认不再自动播 | 与 §四 状态机一致 |
| 可否重复播放 | 可以，从"行迹/回忆"主动回看；回看**不发任何奖励、不推进章节** | 复用同一 `cutsceneId` 完成标记 |
| 状态机 | `NotStarted → Playing → Completed`；另记 `Skipped` | `Skipped` 不默认等于 `Completed` 的奖励语义，但本段无奖励，故两者对存档等价（只写"已看过"） |
| 播完做什么 | 只做一件事：置"已看过"标记，然后进命格揭晓 → 起名 | 播放期间不写章节、不发奖（§四） |
| 跳过键 | 开播 0.5 秒后才可点，避免误触；ESC / 手柄 B / 屏幕右上"跳过"三处一致；单击即走，不再弹二次确认 | 本段无剧情选择，二次确认只是折磨 |
| 跳过落点 | 直接到 F8 标题卡后的命格揭晓，**不跳过起名** | 起名是玩法不是过场 |
| 失败兜底静帧 | 无论哪一镜失败，落到 S3 镇景静帧 + 一行字幕 + "继续 / 重试" | 静帧必须是已入库资产，不能是视频首帧 |
| 素材缺失 | 缺任一静帧则该镜直接跳过（总时长自适应缩短），绝不黑屏 | 静帧缺失概率远低于视频解码失败 |
| 字幕 | 独立层、独立开关、字号可调、避开上下 8% 安全区；老者的三句独白为**逐句切**，每句停留不短于 2.5 秒 | §四 要求字幕不得只烧在视频里 |
| 音量 | 过场音走独立音量组（建议新增"剧情"组），受总音量控制；无音轨时静默不报错 | 现有设置只有总/音乐/音效三档（`FrontEndSettings.cs`），需扩展 |
| 幂等 | 以 `cutsceneId` 先查后写，与章节结算同一逻辑事务；重复回调/读档重开/连续双击结束均不得重复推进 | §四 原文要求 |
| reduceMotion 开启 | 全程序动画冻结：不做视差、不做呼吸、不做闪烁；改为**四张关键帧逐格淡切**（每格 2 秒）+ 字幕可直读；总时长压缩到 6 秒 | §四 要求"静态关键帧/淡切 + 跳过动画直读字幕" |
| 低配降级 | 雾层 3→1、浮尘 16→6、灯火点阵减半、更新频率 30→15Hz；仍不达标则直接走 reduceMotion 路径 | 不新造档位，复用同一开关 |
| 与存档 schema | 需要新增一个"过场已看过"标记位。**本文不定义 schema**，交青衡与主架构师审；倾向复用 `ChapterLedger` 边界而非新表 | 防 UI 直改存档字段 |

## 5. D. 音频方案

| 声音 | 来源 | 授权要求 | 首版建议 |
|---|---|---|---|
| 风 / 高空气流（F3） | 程序生成：白噪 + 低通 + 慢速 LFO | 无 | 直接用 |
| 灯火噼啪、烛芯爆响 | 程序生成：短脉冲 + 带通，随机间隔 | 无 | 直接用 |
| 一声远处木门/风铃（替代初啼） | 程序生成：正弦 + 快速衰减 + 混响 | 无 | **首版用这个替代婴啼** |
| 初啼（真实人声） | 必须授权采样，或请人录音并签授权 | 有 | 二期再上，不在首版 |
| 老者三句独白（配音） | 需 TTS 商用授权或真人配音授权 | 有 | 首版**只有字幕，无配音**。老者的语气是重要伏笔，宁可先空着 |
| 环境底噪（夜虫） | 程序生成：多正弦随机相位 | 无 | 可选，音量压极低 |

纪律：
- 不擅自使用任何来源不明的音效、音乐、人声采样；不下载素材站的"免费"包直接入库。
- 所有非程序生成的音频必须附**授权凭据 + 来源 URL + 授权范围（是否商用/是否可改）**，与资产一起入库。
- 程序生成音频的合成参数写进记录，保证可复现。
- 首版音频总量目标：2 条程序音轨（风、灯火）+ 1 条点睛音（门/铃）+ 静默余量，总大小 < 200KB，避免为一段 10 秒过场引入解码负担。

## 6. E. 与登录页的关系

两件事，不要混：

| | 登录页 / 启动菜单循环 | 序章过场 |
|---|---|---|
| 目的 | 停在原地也不闷，给"江湖乱世"的第一印象 | 讲一件事：一缕魂落进人间 |
| 结构 | 无缝循环，首尾同帧，可无限播 | 单向推进，有终点，不可循环 |
| 视觉母题 | 炊烟与烽烟（丹青 A 方案） | 星海 → 云 → 灯火 → 窗烛 |
| 时长上限 | 单段循环 ≤ 8 秒；靠程序层做无限感 | 短版 10 秒 / 完整版 26 秒，一次播完 |
| 分辨率 | 1920×1080（与菜单底图同族），另出 2 倍图供推镜裁切 | 同 |
| 声音 | 环境氛围，随音乐音量，可完全静音 | 有点睛音，走剧情音量组 |

资产复用规则：

- **可复用**：程序雾层、浮尘、暗角、烘焙光影遮片、字幕组件、淡切工具、调色 LUT。
- **不可复用**：主视觉静帧。玩家在菜单刚看过"炊烟与烽烟"，过场第一眼又是同一张图，观感会掉一半，也会让"星点落进人间"这个叙事失去新鲜感。
- **例外**：镇景静帧（S3/F4）可在**章节标题卡**与未来的"回不去也忘不掉的青石镇"结尾复用——它属于剧情资产，不属于菜单资产。
- 两套资产的**色彩锚必须同族**（同一套靛青+暖橙、同一纸质），否则从菜单点"启程"进过场会有一次突兀的换风格。

## 7. F. 生产顺序与验收

每一步通过才进下一步，任何一步人眼不过就停在这一步改，不往下赶。

| 步 | 做什么 | 验收标准 | 人眼检查点 |
|---|---|---|---|
| 1 | 定 3 张静帧的美术规格（构图、色彩、尺寸、无文字） | 规格表可执行，与丹青菜单锚点同族但不重复 | 与菜单图并排看，像同一个世界、不是同一张画 |
| 2 | 产出**镇景静帧**（S3/F4 共用），走已批准的单张生成或手绘 | 1920 宽以上、无文字、无现代物、缩到 320px 缩略图仍认得出是山村 | 只看缩略图：能不能一眼看出"有人住"。看不清就是废稿 |
| 3 | 产出窗景静帧 + 命盘/老者剪影（可由现有立绘剪影改造） | 窗格透视正确，烛光有实体光源位置 | 剪影里看不出年龄与身份 |
| 4 | Unity 内程序层 spike，只用占位图 | 三层雾 + 灯火 + 烛火 + 淡切可跑；reduceMotion 全冻；无每帧分配 | 关掉所有程序层只剩静帧时，画面不能崩（说明静帧本身成立） |
| 5 | 拼短版 10 秒全静帧版 | 连播三遍不跳、不闪；跳过键任意时点可用 | **关键一关**：连起来要像"一个镜头在动"，不能像 PPT 换页。像 PPT 就回去改运动曲线，不是加生成 |
| 6 | 字幕 + 音频 + 失败兜底接线 | 字幕可关；静帧兜底可点；重复播不重复写档 | 拔掉一张静帧再跑，必须优雅降级不黑屏 |
| 7 | 完整版 26 秒组装 | 同上，时长与节奏对表 | 26 秒看不腻；老者三句独白不抢画面 |
| 8 | 才考虑是否用生成替代 F3 穿云 | 只跑 1 次单镜，必须与第 5 步的程序版做同机位对比 | 生成版必须明显更好，否则不留 |
