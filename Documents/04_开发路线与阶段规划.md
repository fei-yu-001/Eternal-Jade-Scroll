# 一、六阶段开发路线

## 阶段 0：项目初始化（1 周）

- 环境搭建（Unity / IDE / Git）
- 仓库骨架 + 文档体系
- 验收：Unity 项目创建成功

## 阶段一：Unity + C# 基础（1-2 个月）

- 目标：**"能移动的小人"**
- 内容：WASD 移动、摄像机跟随、Tilemap 地面、第一个对话、第一个任务
- 验收：一个可操作、有反馈的最小闭环

## 阶段二：青石镇 Demo（3 个月）

- 目标：第一个可玩版本（v0.1）
- 内容：青石镇地图、4 个 NPC、任务链（后山异动 / 玉石之谜）、对话系统、存档
- 验收：能从头玩到章节结局

## 阶段三：RPG 系统（6 个月）

- 目标：战斗 + 成长闭环（v0.2）
- 内容：属性系统、背包、装备、回合制战斗、五行克制、境界突破

## 阶段四：网络化（6 个月）

- 目标：客户端服务器联通（v0.3）
- 内容：SpringBoot 服务器、登录、存档上云、HTTP 通信
- 与课程对应：Java / 数据库 / 计算机网络（408）

## 阶段五：世界系统（长期）

- 目标：多区域世界（v1.0）
- 内容：声望、门派、经济、落霞城、青云山、世界事件

## 阶段六：AI 增强（长期）

- 目标：AI NPC 特色
- 内容：本地 Qwen 驱动 NPC 对话 + 记忆
- 特色定位：会记住玩家行为、因玩家选择改变命运

# 二、推进原则

1. **完成一个阶段再进入下一个，不跳阶段**
2. 服务器部分（Java / SpringBoot / MySQL / Redis / Linux）与课程、408 对应，可结合课程并行推进，但游戏主线永远先做客户端
3. AI 部分（Qwen）是长期特色，不是前期任务
4. 每周一个小闭环，每天至少一次 git 提交

# 三、毕业目标（能力模型）

```
底层：C/C++
  +
游戏：C# Unity
  +
后端：Java SpringBoot
  +
系统：Linux
  +
AI：本地模型部署
```

这套组合对应：**游戏开发 + 后端工程 + AI 应用 + 系统能力**，属于"全栈偏底层"路线。

> 详细学习路线（六阶段课程对应）见 `12_学习成长记录.md`。

# 四、AI 协作规则

- AI 解释、分析、提方案、协助 Debug
- AI 不直接生成整个项目，不复制不理解的代码
