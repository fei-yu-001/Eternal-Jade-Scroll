# 一、项目定位

《十二玉楼长生经》是一款：

> 以元末明初为历史背景，融合江湖、修仙、探索、经营、NPC 关系模拟的二维开放世界角色扮演游戏。

**玩家不是固定英雄。玩家只是乱世中的普通人。**

通过：选择、行动、修炼、人际关系，逐渐改变自己的命运。

# 二、核心设计理念

## 1. 命运不是固定的

玩家出生时随机生成：血脉、灵根、气运、家世。

- 例如出生"天生剑骨"：适合剑修
- 或者"凡人之躯"：但商业能力强

开局以"投胎问命"作引导：投胎之前，一缕前生魂魄在轮回渡口与守渡老者对答六问，每答一问点亮一道命盘脉络；答案只为命格加权，最终仍由随机落定——**问命是算命，不是捏人**。（序章流程与六问脚本详见 GDD 六、出生系统）

## 2. 世界不会围绕玩家转

NPC 拥有自己的生活。

例如铁匠每天上午打铁、下午卖装备；如果玩家长期不帮助他，他可能离开村庄。

## 3. 玩家行为产生长期影响

- **善**：获得声望、人脉、资源
- **恶**：获得财富、力量，但受到追杀、通缉

# 三、世界观设计

- **世界**：玄黄界（《千字文》"天地玄黄"；详见 GDD 3.1）
- **时间**：元末明初
- **天下**：战乱，皇权更替，江湖混乱
- **与此同时**：天地灵气逐渐恢复

# 四、修行体系

世界以灵气道（修仙）为显学，但条条大路通罗马——武、文、医、商诸道皆有三段九重，文人也能悟道成圣：

```
通用骨架：凡俗段（一至三重）→ 入道段（四至六重）→ 合道段（七至九重）
灵气道：锻体 → 感气 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 真仙
```

功法秘籍天然稀缺：普通家庭得不到或极少得到；命好者有祖荫，命薄者靠机缘（采药坠崖得遗蜕、助黑衣人得玉牌、说书老人赠书、河中捞铁盒……）。详见 GDD 七、八节。

# 五、十二玉楼设定（整个世界核心）

传说：天地初开，有十二座仙楼降临人间。每一座玉楼代表一种大道。

| 楼 | 名 | 大道 |
|---|---|---|
| 第一楼 | 太玄楼 | 剑道 |
| 第二楼 | 天机楼 | 推演 |
| 第三楼 | 长生楼 | 生命 |
| 第四楼 | 万象楼 | 变化 |
| …… | …… | …… |

**最终：十二楼合一，可窥长生。**

> 注：十二楼完整名单（含传承 / 能力 / 象征）见 `02_游戏设计文档GDD.md` 第四节。

# 六、主线剧情设计

## 第一篇：凡尘篇

- 地点：青石镇
- 玩家：普通少年
- 事件：村庄遭遇妖兽
- 发现：神秘老人，守护十二玉楼秘密

## 第二篇：江湖篇

玩家进入武林，加入：门派 / 镖局 / 商会

## 第三篇：仙途篇

发现：江湖纷争背后存在修仙势力

## 第四篇：天门篇

寻找十二玉楼。决定：成仙？救世？建立自己的道路？
