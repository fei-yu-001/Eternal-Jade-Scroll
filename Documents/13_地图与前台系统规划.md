# 二、M1 地图场景与小地图（已实装）

> **2026-09-28 进展**：地图 v3 密集主街（鸟瞰透视，角色按 y 缩放 0.72→1.05）+ 六关节分层纸偶。**数据已外置**——走廊、立绘、地标、出生点、透视上下限全部落在 `Resources/Config/town-map.json`，`TownMap.Parse` 读表并做画布越界、走廊连通、出生点可达、洪水填充可达面积等校验（校验在 `Tools/SaveChecks`，改坏了先在测试里报警）。**手感细节补齐**：脚步尘点（八枚循环的淡墨点）、转向缓冲（80ms 挤压过渡）、步频与速度联动、小地图金点加墨边 + 朱红地标点、点舆图展开全图浮层。**立绘与纸偶的枢轴统一取底边**（`pivot.y = 0`）：配置坐标即地平线，纵深排序才是"谁站在谁前面"。

## 2.1 场景结构

- **整卷水墨地图**：不用标准 Tilemap 拼块——水墨风拼块会露出接缝。改为"一卷一画"：每张地图是一幅 1920×1080（或更宽的卷轴）水墨背景画（grok 生图 + 原图归档，走既有管线），可行走区域用**可行走多边形**手工圈定（编辑器里存成点位表 JSON）。
- **障碍表示**：多边形可行走区之外皆不可走；建筑、山石等大件另配圆形障碍列表（圆心+半径），寻路时绕行。数据全部配置化（第二原则）。
- **地图清单（第一章）**：青石镇内（主街/集市/村塾/码头）、镇郊小秘境入口、后山道。三张起步。

## 2.2 行走与操作

- **操作**：鼠标点击地面即走（落点显示一圈水墨涟漪标记），WASD/方向键即时移动；两种输入共存。
- **朝向**：按移动方向左右镜像立绘（沿用 uvRect 翻转）；斜向保持最后朝向。
- **状态机**：Idle ⇄ Walk ⇄ Run（按住 Shift），接现有 `CharacterActor` 的动作与过渡权重；上/下坡只在视觉上允许（地表平坦，起伏靠背景画表达）。
- **行走手感细节**（用户点名的细节刻画）：
  - 脚步尘点：每步触地时在脚下生成一枚淡墨尘点，0.4s 淡出（对象池，单图上限 8 枚）；
  - 转向缓冲：镜像翻转瞬间不做 180° 硬切，加 80ms 的 squash 过渡；
  - 移动速度与步频联动：步频 = 基础步频 ×（速度/基准速度），跑动时尘点更大更浓。

## 2.3 相机

- 跟随角色，SmoothDamp 缓动（follow ~0.15s），地图边缘钳制不出卷轴；小地图同步。
- **现状**：青石镇一卷 1920×1080 单屏放下，暂无跟随；等出现多屏地图（如后山道）再接。

## 2.4 小地图

- 右上角宣纸小地图：主图纹理等比缩放绘制（同一张背景画，不另做图），外圈深墨框；
- 元素：玩家金点（带墨边，22px + 30px 光晕）、地标朱红点（位置来自 `town-map.json` 的 `landmarks`）；
- 点击小地图：打开大地图浮层（本卷全图 + 地标名 + 图例），不做跨图传送（第一章无传送）。

## 2.5 验收标准（M1 完成定义）

- [x] 青石镇一张图：点击行走 / WASD 移动 / Shift 跑动，动作与尘点正确；
- [ ] 相机跟随平滑、边界不穿（单屏地图，暂不适用，随第二张图接入）；
- [x] 小地图玩家点实时同步、大地图浮层可开；
- [x] 障碍不可穿行（贴着圆障碍走会被滑开而非卡死）；
- [x] Unity 批处理验收 0 problem + 地图页截图人工验图；
- [ ] 实机手感复核（尘点密度、转向挤压幅度、步频）——需玩家本人跑。

# 三、M2 背包（已实装）

> **2026-09-28 进展**：物品表落在 `Resources/Config/items.json`（18 件，含 5 阶 6 类、堆叠上限、基准价、批语式描述、图标名）；`ItemTable.Parse` 读表并校验品阶/类别引用、堆叠范围、id 唯一性，配置坏了先在 `Tools/SaveChecks` 里报警。行囊规则 `InventoryRules`（堆叠/放入/取出/换位/整理/校验）与声望折扣 `Reputation` 都在 Core 层、无 Unity 依赖。存档升到 v3（`coins` / `localReputation` / `bag` 24 格），旧档读取即迁移补上开局行囊与盘缠。界面：24 格宣纸格、类别页签、说明面板（悬停 150ms 延迟换文字）、拖拽换位、双击使用、整理、铜钱与声望摘要。入口为城镇页「行囊」按钮与 `B` 键。

## 3.1 结构与细节

- **24 格宣纸背包**（6×4），格子底用现有象牙宣纸色；物品图标复用 `Items/` 已有 19 张（丹药、干粮、玉佩、柴刀、符纸……）。
- **说明面板**：常驻单面板换文字——未选中时写"怎么用"，选中后写品阶色名称 + 批语 + 类别/数量/市价。（早前是"常驻层 + 浮签层"两块面板互切显隐，只要有一处漏恢复就留空白，已改为单面板。）
- **页签**：全部 / 丹药 / 吃食 / 材料 / 器用 / 兵器 / 任务物——数据驱动，页签本身由物品表的 `categories` 生成，加一类 JSON 即多一个页签。
- **物品表**（`items.json`）：id、名称、描述、品阶、类别、堆叠上限、基准价、图标；**不写死代码**。
- **操作**：左键选中、拖拽换位（同类合并、异类交换）、双击使用（只对吃食/丹药生效，任务物拒绝）、一键整理；背包满时新物品触发"行囊已满"提示（就地丢物需二次确认——财不外露机制会盯上地上的东西）。

## 3.2 验收标准

- [x] 存档持久化背包内容（SaveRepository v3 schema，旧档迁移）；
- [x] 说明面板、页签、拖拽、堆叠（干粮×5 一格）全部可用；
- [x] 批处理验收 0 problem + 截图验图（9 页，含 inventory）；
- [ ] 实机试玩：拖拽手感、浮签 150ms 延迟是否仍刮蹭、页签过滤后的空格表现。

# 四、M3 交易所（买卖）

## 3.1 结构与细节

- **入口**：与商人 NPC 对话选"做买卖"进入；不同商人各有一张 **商品表**（JSON：物品 id、存货、基准价、愿意收的二手品类）。
- **买卖双栏**：左"他的货"右"你的行囊"，中间铜钱结算；买卖都有 200ms 的铜钱飞扣动画与算盘音效位（音效后续接入）。
- **价格细节**：基准价 ± 声望折扣（八节善名线：本地声望每档 -3%，上限 -15%）；深夜找货郎可开**黑市页**（杀星入命/龙蛇命可见更多条目）——价格 ×1.4 但有独门货。
- **NPC 记忆联动**：买卖次数写入商人记忆层（"这后生在我这买过三回干粮"），好感与对白随之变化。
- **防呆**：卖出有二次确认（误卖任务物会坏剧情）；铜钱不足时按钮禁用并显示差额。

## 3.2 验收标准

- [ ] 与货郎完成一轮买+卖，铜钱、存货、声望折扣数字正确；
- [ ] 商人记忆随交易变化（对白可查）；
- [ ] 数据表驱动新增商品不改代码（加一条 JSON 验证）。

# 五、角色表现升级路线（解决"木偶感"的根本方案）

## 5.1 现状

单张立绘整体位移（`CharacterActor` 程序动画）。已做：快起缓落步弧、触地挤压、交替摆动、过渡权重。上限：没有关节，永远是"纸片整体动"。

## 5.2 分层纸偶（M4 前置，中期方案）

- **拆三层**：立绘横切为 头部层 / 躯干层 / 下肢层（生图时按图层分开出图，或抠图拆分），各自设枢轴：
  - 下肢层：原地交替小幅摆动（走路核心）；
  - 躯干层：随步伐 1 帧滞后的次级摆动（反作用力感）；
  - 头部层：再滞后 1 帧 + 轻微上下浮动（视线稳定感）；
  - 三层相位差 = "活"的关键，正是木偶与真人的分界。
- **拆图管线**：`Tools/split-puppet-layers.py`——按水平切线 + alpha 通道拆分，接缝处用颜色回填；先拿 farmer 一套做样板验证。
- **打斗动作**（M4 本体）：在分层纸偶上做状态机——前摇（躯干后倾蓄力）→ 挥击（武器层 90° 弧线 + 一帧残影）→ 后摇 → 受击（闪白 60ms + 击退 + 顿帧）→ 闪避"见切"（时间凝滞 120ms）；打击感三件套：**顿帧、闪白、尘土**一个不少。

## 5.3 长期（出美术量后）

- 行走循环多帧图（每角色 6–8 帧）由生图管线出稿再人工修帧；骨骼方案（Unity 2D Animation）作为优化选项评估，不先上。
