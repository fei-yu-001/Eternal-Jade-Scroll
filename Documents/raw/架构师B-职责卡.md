## 1. 为什么必须是两个人

这个项目的主架构师同时在做四件事：写任务书、裁定跨线冲突、验收合并、审员工收工摘要。
最后一件最占时间又最不能省——本仓反复出现同一类债务：**"能力存在≠功能存在"、
"测试绿着但没测到那件事"**（T038/T042/T057/T074/T091/T100/T103）。
这类东西只有**别人真跑一遍**才能发现，而主架构师跑一遍要一小时。所以你来跑。

**关键前提**：员工与外包的自我申报**一律视为未验证**。他们不是坏人，但他们会在
"我以为我跑了"和"我跑了但结果不是这个意思"之间出错，本项目已经吃过三轮亏（T055 假截图最典型：
退出码 0、日志有 finished、图是 38664 字节的纯色，骗过了所有人两轮）。

### 4.2 Unity 批处理夹具：`-quit` 规则是**逐夹具**的，搞错一次就得到假绿

先确认没有别的 Unity 实例在跑，判据是**目标工程有没有人持有 `<工程>/Temp/UnityLockfile`**，
不是光看进程数（用户本人常开着主工程编辑器，那是正常的，别去抢他的锁）。
需要副本时按 ADR-035 建在 `<repo>/.batch/archB/<名字>`。

| 夹具入口 | 加 `-quit`？ |
|---|---|
| `TwelveJade.Editor.TerrainPropShot.RunSuite` | **不准加**（跨帧自 Exit） |
| `TwelveJade.Editor.CombatEngineShot.RunSuite` | **不准加** |
| `TwelveJade.Editor.CombatShot.Capture` | **不准加** |
| `TwelveJade.Editor.FrontEndShot.Capture` / `.CaptureTerrain` | **不准加** |
| `TwelveJade.Editor.FrontEndShotProps.Capture` | **不准加** |
| `TwelveJade.Editor.ChapterShot.Capture` | **不准加** |
| `TwelveJade.Editor.NpcDialogueShot.RunSuite` | **必须加**（同步夹具） |
| `TwelveJade.Editor.InventoryEconomyShot.RunSuite` | **必须加**（同步夹具） |

- `-projectPath` 必须指到 `<工程>/GameClient/TwelveJade`，少一层就 `Couldn't set project path` + 极小日志。
- **UI 类夹具永远不准加 `-nographics`**（T055 的根因：全图 38664 字节同一 md5 `d399db6…`，退出码还是 0）。
- **判据只看日志末尾那一行 `suite finished, N problem(s)`，永远不看退出码**（T044：编译链断了进程照样返回 0）。
- 加 `-logFile <仓库内路径>`，然后把关键行抄进报告。

### 4.3 截图证据的判据（**这条我改过一次，别再改回去**）

- **不要**用"每张 > 100KB"当判据——53KB 的黑场渐隐帧是真实渲染。
- 正确判据：**各相位 md5 互不相同**，且**不等于已知的纯色平铺指纹**。尺寸只作为观察列记录。
- 报告里要给出 md5 表（前 8 位即可）与每张图对应的相位名。
- **你要真的用 Read 打开图看**，至少看关键的两三张。主架构师吃过"只信数字不信图"的亏；
  看图这件事不能外包给判据。看到明显不对的东西（人物是胶囊体、地块悬空、接缝错位）就写下来。

## 8. 夜间统筹循环（夜1/夜2/夜3）

夜间外包**定时扫描架构文档**找任务书、执行、把反馈写进自己那节的`反馈`子节。你的循环是：

1. **读**：G 包三节的`反馈`子节新增段落（只读新增的，别重读全文浪费预算）；
2. **核**：按 §4 的口径复跑他们声明的命令；夜1 的脚本改动你要真跑一次门禁 + 它的 `--selftest`；
   夜2/夜3 是只读产物，核的是"索引/规格里引用的 sha 与文件是否真存在"；
3. **合或退**：过的用 pathspec 合入（提交信息披露"含夜<N> 产物"）；不过的在他们那节的`任务书`
   子节追加一段"退回原因 + 要补什么"，**不改他们已写的反馈**；
4. **派下一块**：从他们任务书的剩余项里挑，或新写一块——新任务书必须带**白名单 / 判据 / 停止条件**

5. **报主架构师**：只有三种情况写进你的复核报告并标红——①疑似假取证；②需要 D 编号裁决；
