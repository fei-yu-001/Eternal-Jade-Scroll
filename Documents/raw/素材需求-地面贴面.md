# 素材需求｜战斗页地面贴面（提给夜间素材线 / 统筹席 B）

**提出人**：开发者2号（员工 N）｜2026-10-06｜依据：交接包 I-4「我看图新出的两条」+ I-5.6
**落点**：`GameClient/TwelveJade/Assets/Resources/Art/Combat/`（建议文件名 `stage-ground-ink.png`）
**我不生图**：I-5.6 明令"不要自己拿 grok 生图——那是夜4 的活，越界会撞风格锚点"。本文件只是需求单。

## 为什么要

战斗页的"地面"原来是 `UiKit.Panel` 画的**浅灰圆角矩形**（`RoundedSprite` + Sliced）。
圆角 + 均匀填充 + 硬边框是 UI 面板的语言，摆在战场里读起来就是"一块控件压在地上"，
不是地。主架构师 I-4 的原话：**"读起来像 UI 面板而不像地面——这是程序化占位件当美术件用的典型症状。"**

本轮（N4-Polish）我已经用仓库里现成的 `Art/Fx/ink-stroke`（水墨笔触）**顶了一下**：
把笔触裁到 alpha 包围盒后横向铺满战场矩形，透明度 0.30。它比圆角矩形像地得多，
但**它不是一张合格的地表**，原因见下面"必须满足"的第 1、3 条。所以这张需求单要提，
顶替方案只活到真贴面到货为止。

## 必须满足（判据是看图，不是断言）

1. **横向可平铺**：左右边缘必须无缝（同一张图横向复制两份看不出接缝）。
   现在的 `ink-stroke` 是一笔写出的钩形，两端各有独立的收笔，平铺会出现"两笔"的断裂感。
2. **尺寸**：画布 1500×120（战场那块地的实际像素范围是 x 460..1460、y 约 706..812，
   按脚点线铺），留透明边距不超过画布高的 10%。
3. **边缘磨损、无 UI 感**：不许有圆角、不许有均匀纯色填充、不许有硬边框。
   上沿要淡出（远端的雾/纸纹），下沿可以稍实（近处的土），中间允许留白。
4. **风格锚点**：与 `STYLE_ANCHOR` 一致的水墨淡彩、生宣纸纹、低饱和；
   主墨色建议 `#2A2E28` 一档，透明度做在图里而不是靠运行时染色。
5. **不要画任何东西上去**：不要草、石头、脚印、路径花纹——那些是场景件，会跟
   `Art/Props/` 的立件打架。这张图只负责"这里有一块可以站着的地"。

## 到货之后我怎么接

`FrontEndCombat.InkWashTexture()` 的取图路径改成先试 `Art/Combat/stage-ground-ink`、
取不到再退回 `Art/Fx/ink-stroke`；夹具里那条
`地面是真贴面而不是浅灰圆角矩形（取不到贴面就红，不许静默降级成 UI 块）`
**不需要改**——它钉的是"取不到就红"，换图不会让它失效。
另外还有一条 `妖的可见脚点踩在地带之内` 守着几何，换图之后如果画得太高/太矮把脚点盖掉了，
那条不会红（它只看地带矩形），**仍然要人看图**——这条我在 `Tools/logs/n4-polish-report.md` 里写明了。
