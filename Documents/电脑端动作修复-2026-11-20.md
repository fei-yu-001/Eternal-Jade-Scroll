# 电脑端技能尺寸与 NPC 动作修复（2026-11-20）

当前开发从本记录接续。正式工程为 `GameClient/TwelveJade`，Unity 6000.3.25f1；本轮暂停鸿蒙联调，完成电脑端技能尺寸、NPC 步态和关联搭话卡路修复。所有 Unity 检查在独立 `.batch/DesktopMotion` 副本运行，未降级正式工程。

## 改动与原因

### 释放技能时角色变大

`ActionCombatPose` 在攻击、闪避和减弱动态分支把根节点缩放设成 one，覆盖 `PuppetActor` 的 0.8 / 1 / 1.25 档位。另一个问题来自素材矩形：站姿按 170 高显示，攻击按 450 像素人体撑高，默认 1 档可见高度也会增加 4.86%–8.05%。

现在动作读取角色基础缩放，按实际站姿方向和攻击帧的透明边界独立校准可见身高、鞋底。闪避仍使用原行走帧矩形及既有形变。新增纯计算 `ActionPoseGeometry`，用独立 PNG 测量核对注册数据；运行时不要求纹理可读。以后换这些 PNG 必须重跑素材和 Unity 检查。

### NPC 生硬、像在滑行

原动画按显示节点的位置差推步态，缩放和位置重排容易干扰；旧步长导致速度 26 时约 0.654 秒才换一帧。现在由巡游碰撞检查、地图圆心写回成功后的真实世界位移推进步态，11 位 NPC 明确配置每 26 单位一轮，常速时约每 0.25 秒一帧。原地、搭话、禁用和离场回到站姿；近乎竖直走时忽略微小水平噪声，避免左右抖动。

巡游增加约 0.12 秒起步、0.18 秒制动，按剩余路线减速，并在转弯前降速。保留每帧逐段碰撞复核、动态 NPC 阻挡和原有返回真实位移的契约。未重画或替换美术。

### 实际搭话时卡路

真实城镇测试发现玩家已走进货郎的 200 单位对话距离，仍追向 NPC 另一侧的最终落脚点；中途遇阻使 NPC 持续暂停等候。`RequestTravelTo` 增加可选到达条件，仅搭话传入实时 `DialogueDistance`。进入有效距离便完成搭话；新请求覆盖、取消或完成都会清理条件，其余点地/遭遇/采矿保留原路点判定。最后实跑在距离 196.418 时打开对话，关闭后恢复巡游。

## 本地复验入口

先加载工作区 `tools/Use-Tools.ps1`，工具和缓存优先使用 D 盘。技能复验步骤见 `Tools/ActionPoseChecks/README.md`。

- `dotnet run --project Tools/NpcLocalPatrolChecks/NpcLocalPatrolChecks.csproj`
- `dotnet run --project Tools/NpcDynamicBlockerChecks/NpcDynamicBlockerChecks.csproj`
- Unity 有图形批处理：`TwelveJade.Editor.NpcMotionShot.Run`，设绝对路径 `JADE_DESKTOP_EVIDENCE`，仅在 `.batch` 副本运行。
- Unity 非 batch 独立编辑器：`TwelveJade.Editor.NpcLocalPatrolShot.Run`，设 `NPC_PATROL_EVIDENCE` 为全新空输出目录，`NPC_PATROL_SOURCE_PROJECT` 指向正式 Unity 工程。夹具使用独立存档并比对源文件哈希。

最终本地证据在被忽略的 `Tools/logs/desktop-review-20261120`：技能 `action-pose-unity/report.txt`、NPC 素材 `unity/`、真实城镇 `npc-playmode-v3/runtime-results.json` 与 `frames.jsonl`。过程中的失败运行保留以便追溯：技能夹具先修复了未保存场景的初始化及预览 UI 出图；城镇发现并修复搭话卡路；步态采样区分真实微小末步与严格静止，未放宽实际碰撞/暂停/身高判据。原始日志和图片不进公开仓库。
