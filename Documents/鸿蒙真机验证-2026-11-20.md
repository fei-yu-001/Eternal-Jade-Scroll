## 已知范围与下一步

当前成功的是 API 26 手机的最小引擎工程。导出保留模板 Hvigor modelVersion 6.0.0、compatibleSdkVersion 5.0.2(14)，未显式设置 targetSdkVersion；安装包实际 targetVersion 为 260001026。模板仍有 API 20 调用与 API 14 最低版本声明不一致、资源重名、ArkTS ESObject 等警告。没有在低版本设备验收兼容性，正式迁移时应明确最低/目标 SDK 并处理相关告警。

正式客户端仍是 Unity 6000.3.25f1，Input System 1.17 和 UGUI 2.0。下一步用独立副本评估团结 2022 对这些包和 API 的兼容性，再接入游戏场景、触控入口、账号云存档和性能检查。不得用团结直接降级正式工程，也不能将本次测试 HAP 当作已完成的手机游戏。

本轮未改玩法、地图、服务器部署或自动上下文压缩配置。既有架构问题与历史测试结果继续以 [架构审查](架构审查-2026-11-20.md) 为准。
