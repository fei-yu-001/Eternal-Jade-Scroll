# 一、章节定位

- 章节名称：**第一卷：青石残梦**
- 地点：青石镇
- 玩家等级：1-10 级
- 主要目的：让玩家理解世界、NPC、任务、战斗、修炼

# 二、章节核心主题

## 凡人亦有长生路

玩家开始只是普通人。没有逆天实力，没有天命身份。但是：一次选择可能改变未来。

# 四、主要 NPC 设计

## NPC001 老村长——沈怀安

| 项 | 内容 |
|---|---|
| 年龄 | 72 岁 |
| 身份 | 青石镇村长 |
| 职业 | 普通老人 |

- **人物背景**：年轻时曾是江湖游侠，后来因为某件事情退出江湖。隐藏身份。
- **性格**：智慧 90 / 善良 80 / 谨慎 95 / 勇敢 70
- **初始状态**：对玩家陌生
- **隐藏设定**：知道十二玉楼残片，但不愿提起
- **任务作用**：负责主线引导

## NPC002 老铁匠——赵铁山

| 项 | 内容 |
|---|---|

# 五、第一章剧情流程

## 开始

玩家来到青石镇，触发新手剧情。

村民："最近后山有怪物出现……"

玩家获得任务：《后山异动》。

# 六、任务链设计

## 主线任务 001：后山异动

- **发布**：沈怀安
- **目标**：调查后山

流程：

```
进入后山 → 发现妖兽 → 击败 → 发现奇怪玉石 → 返回村庄
```

**奖励**：经验、铜钱、声望、获得**玉楼残片**

## 主线任务 002：玉石之谜

- **发布**：沈怀安
- **目标**：寻找玉石来源

流程：

```
询问NPC → 铁匠：发现玉石特殊 → 药师：发现灵气 → 老人：产生特殊反应
```

最终：开启隐藏剧情。

# 七、隐藏任务

## 断剑重铸

- **触发条件**：铁匠好感 > 80
- **剧情**：铁匠年轻时留下的一把断剑，玩家寻找材料
- **最终获得**：青锋剑
  - 属性：攻击 +15
  - 特殊：剑修成长增加

# 八、第一章结局（三个方向）

## 结局 A：平凡生活

玩家选择离开玉楼秘密，成为普通侠客。

## 结局 B：踏入修仙

获得第一块玉楼碎片，进入修仙道路。

## 结局 C：黑暗道路

抢夺玉楼碎片，成为被追杀者。
