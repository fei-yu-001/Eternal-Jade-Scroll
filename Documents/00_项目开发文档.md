# 一、项目概览

| 项 | 内容 |
|---|---|
| 项目名称 | 十二玉楼长生经（Eternal Jade Scroll） |
| 类型 | 2D 开放世界修仙 RPG（区域式开放世界，类星露谷） |
| 世界观 | 玄黄界，元末明初（第四纪元·大劫时代），灵气复苏 |
| 核心特色 | NPC 有自己的生活并记住玩家行为，玩家选择改变世界 |
| 客户端 | Unity（2D）+ C# |
| 服务器 | SpringBoot + MySQL（阶段四）+ Redis（后续） |
| AI 方向 | 本地 Qwen 27B 驱动 NPC 对话（阶段六，长期特色） |
| 开发模式 | 个人独立开发 + AI 辅助 |
| 项目双重目的 | ① 长期游戏项目 ② 技术成长 + 毕业答辩 + 考研 408 + 简历素材 |

**一句话定位**（简历 / 答辩用）：
> 一个"传统游戏系统 + AI 智能 NPC 实验平台"的 2D 开放世界修仙 RPG。

# 二、三条设计原则（铁律）

1. **系统优先** —— 不要为了剧情牺牲系统
2. **所有内容数据化** —— 不写死，任务 / 物品 / NPC 都读配置
3. **允许玩家创造故事** —— 系统给玩家留出创造空间

> 任何违背以上原则的设计或代码，记录到 `11_技术债务记录.md`。

# 三、总体开发路线（六阶段）

| 阶段 | 名称 | 内容 | 时长 | 交付物（验收标准） |
|---|---|---|---|---|
| **阶段 0** | **项目初始化** | **环境 + 骨架 + 文档整理** | **1 周** | **本仓库 + Unity 项目创建** |
| 阶段一 | Unity + C# 基础 | WASD 移动 / 摄像机 / Tilemap / 对话 / 第一个任务 | 1-2 个月 | "能移动的小人"闭环 |
| 阶段二 | 青石镇 Demo | 地图 / 4 个 NPC / 任务链 / 对话 / 存档 | 3 个月 | 第一个可玩版本（v0.1） |
| 阶段三 | RPG 系统 | 属性 / 背包 / 装备 / 回合制战斗 / 五行 | 6 个月 | 战斗 + 成长闭环（v0.2） |
| 阶段四 | 网络化 | SpringBoot：登录 / 存档 / HTTP 通信 | 6 个月 | 客户端服务器联通（v0.3） |
| 阶段五 | 世界系统 | 声望 / 门派 / 经济 / 落霞城 / 青云山 | 长期 | 多区域世界（v1.0） |
| 阶段六 | AI 增强 | Qwen 驱动 NPC 对话 + 记忆 | 长期 | AI NPC 特色 |

**铁律：完成一个阶段再进入下一个，不跳阶段。**

- 服务器部分（Java / SpringBoot / MySQL / Redis / Linux）与课程、408 对应，可结合课程并行推进，但游戏主线永远先做客户端。
- AI 部分（Qwen）是长期特色，不是前期任务。
