# 二、安装步骤（今晚执行）

## 1. Unity

1. 到 https://unity.com/download 下载 Unity Hub
2. 安装 Hub → 登录
3. Hub → Installs → Add → 选 **Unity 6 LTS**（最新 6000.x）
4. 模块确认勾选 **2D (Core)**（默认一般已勾）
5. 装完后新建项目：New → 模板选 **2D (Core)** → 项目名 `TwelveJade` → 位置 `D:\Eternal Jade Scroll\GameClient\`

## 2. C# IDE（三选一）

- **方案 A（推荐）**：VS2022 Community —— 安装时勾选 ".NET 桌面开发" 工作负载
- **方案 B**：VS Code + C# Dev Kit 扩展（VS Code 已装）
- **方案 C**：现有 `D:\ruangong\visualstudio\buildtools`（VS Build Tools 已装但无工作负载）→ 打开 Visual Studio Installer → 修改 → 勾选 ".NET 桌面开发"

> 注意：实测 Build Tools 当前**没有任何工作负载**，不补装无法编译 Unity C#。
