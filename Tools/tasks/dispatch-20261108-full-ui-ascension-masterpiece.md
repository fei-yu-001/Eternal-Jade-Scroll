### 一、制作人最新审判与指令精要

制作人斐哥在深度实机体验后，提交了 11 组实机截图与业界高品质修真参考素材，明确下达了以下 6 项核心整改要求：

1. **会话对话框下移沉底**：
   - 现状：`DialogueUI` 的纸质对白底板（`y=650, h=350`）悬浮于画面中下方，遮挡严重且压迫视野。
   - 要求：整体下移贴合屏幕底边，收拢高度，留出上方开阔空间给立绘与环境，增强沉浸代入感。
2. **鸟瞰全图去“官府衙门味”，重塑仙门水墨青绿舆图**：
   - 现状：`FrontEndWorld.cs:ShowWorldOverlay` 为深绿生硬方盒内嵌灰暗俯视图，红点朱点密布，极具古代官府巡捕防务图既视感。
   - 要求：彻底推翻方盒设计，重构为仙家绢帛展开的“水墨青绿舆图手卷”。采用宣纸底衬、淡墨山峦、灵流祥云缭绕，地标使用朱砂古印与流光标注。
3. **道身面板彻底升华（对标五行灵根与仙尊道影）**：
   - 现状：道身仅为一张单薄黄纸罗列文字，干瘪简陋。
   - 要求：参考制作人给出的典范素材（图 7 莲台道者五行灵根、图 6 金光经络），中央展现修道者打坐入定道影，周身流转五行灵根环（金木水火土），下方聚灵莲台，两侧排列先天命格气运。
4. **八卦莲花罗盘解耦【归卷】并美化虚化底盘**：
   - 现状：`JadeLotusRotator.cs` 将【归卷】作为轮盘 8 槽位之一，玩家旋转选技能时极易误触关掉；底盘深绿大圆盘贴在地面上突兀生硬。
   - 要求：将【归卷】剥离出八卦功能环，移至设置齿轮附近作为独立收卷按钮；罗盘底盘去除生硬黑膏药底，改为镂空浮雕太极金铜阵盘与边缘虚化灵光，自然融入地表。
5. **左侧任务栏重做为“天机卷轴”（点击拉开，再次回卷）**：
   - 现状：左侧常驻任务为一张白色竖向便签信纸，现代网页感重。
   - 要求：重构为古风“天机卷轴”。平时收拢为精致小巧的横轴卷轴，点击时向下拉开丝滑展开卷面，显示任务与金色探求标；再次点击或点边缘丝滑回卷收纳！
6. **功法与技能体系深度融合**：
   - 结合参考图 8（真武八卦技能盘）与图 9/10（主动/被动/心法体系），为后续高阶宗门功法、秘籍学习与肉身成圣打好架构底座。
7. **Q 版秘籍学习动画升华为 2D 漫画感特色小剧场**：
   - 制作人要求：“q版本的密集学习动画可以是2d的漫画版本都可以有咱们自己的特色和小巧思就好”；
   - 引入灵动生动的 2D 漫画分镜小巧思：小道童捧卷参悟、顿悟金光冲顶得意大笑（成功）、若有所思托腮点头（偶得）、以及被秘籍弹翻屁股着地眼冒太极金星（失败）的萌趣治愈演出，注入独一无二的游戏灵魂。
8. **经脉界面彻底剔除“骷髅灵体”，重塑正统道家金光法身/紫府元神**：
   - 制作人痛批：“这个经脉这个感觉也需要优化一下这个骷髅灵体感觉没啥特色”；
   - 彻底废除阴森类似 X 光解剖透视的蓝色发光骷髅骨架，对标参考图 6（天人合一金光经络剪影）与图 7（端庄入定仙尊道影），重构为浩然清圣的紫府元神或金光法身，穴位如周天星宿璀璨流转。

### 二、详细落地技术拆解与模块分工

#### 模块 A：会话对白框下移（`DialogueUI.cs`）
- 将 `DialogueUI.paper` 锚点下移至底边：`y = 730`，高度微调至 `320`；
- 对话选项列表与继续/告辞按钮整体按比例微调，保持呼吸感；
- 立绘根据新下边缘做底部平滑遮罩，保证视觉重心自然聚焦在人物神韵上。

#### 模块 B：青石镇水墨仙山舆图（`FrontEndWorld.cs` / `WorldTerrainImage.cs`）
- 剔除深绿全屏与黑色大方盒；
- 引入古卷展卷动效（从中央向左右缓缓拉开轴心）；
- 底图采用水墨淡彩青绿渲染，地标用仙篆金字与朱砂小印替代现代小圆点。

#### 模块 C：本命道身修真图（`FrontEndCultivation.cs`）
- 左侧/中央：修道者入定冥想道影，背负五行灵根光环；
- 右侧：本命命格（如仁心命、天生词条）、寿元、道龄、宗门与气运；
- 底部：灵根天赋进度与境界突破引信。

#### 模块 D：八卦天机盘优化（`JadeLotusRotator.cs` / `FrontEndGuofengHud.cs`）
- 从 8 槽位中移除 `guijuan`，换入修真核心功能（如【法宝】或【灵根】），或者收敛为 7 曜天机环；
- 【归卷】作为独立的飘带/玉坠收卷控制，挂在罗盘边缘或设置栏旁边；
- 移除底盘外围生硬不透明的深绿大圆，使用透明度过渡与法阵镂空。

#### 模块 E：天机任务卷轴动效（`FrontEndGuofengHud.cs`）
- 封装 `QuestScrollWidget`：
  - 闭合态：宽 320，高 48 的小巧横轴，轴头带青玉轴轴与金色系带，显示简明章节提示与发光金色问号；
  - 展开态：点击轴心平滑向下拉开卷帛（高度自适应展开至 280~360），以毛笔正楷显示目标与线索；
  - 再次点击卷轴头或外部即刻回卷收纳。

#### 模块 F：经脉界面重塑道家金光法身（`FrontEndCultivation.cs` / `meridian-bg.png`）
- 彻底摒弃阴森发蓝的骷髅骨架；
- 重塑为浩然正气的道家天人合一紫府元神/金身剪影，周身环绕星辰微光；
- 督脉任脉等奇经八脉如金色灵河在金身内流淌，冲穴时金光爆破、道韵激荡，展现正统道门清气。

#### 模块 G：Q 版 2D 漫画分镜式悟道演出（`ChibiStudyAnimation.cs`）
- 融入漫画分镜式生动表情与气泡小巧思：
  - 成功：头顶金光冲顶、小金莲绽放，小道童双手叉腰神气活现；
  - 偶得：小手托腮闭目沉吟，浮现篆体古字碎片；
  - 失败：被卷轴弹飞四脚朝天，眼冒转转金星，气泡吐舌自嘲“道心微震”；
- 形成专属于《十二玉京》的标志性可爱治愈彩蛋。
