青岩用 `Get-CimInstance Win32_Process … CommandLine` 打印了 `Unity.exe` 的**整条命令行**，只对 `-username/-password/-serial`
打了码，漏了 Hub 拉起编辑器时附带的 `-accessToken`——**完整的 Unity Hub 访问令牌**连同 `-hubSessionId`、`-cbmEditorLicense`、
`-cbmMachineId` 被原样打进会话终端（未写入仓库任何文件、未进 git）。已报主架构师，由斐哥在 Unity Hub 退出重登使令牌失效。
**纪律**：排查进程（谁占锁、谁在跑、是不是编辑器本体）时，**只取四个字段**：PID、启动时间、父进程 PID、`-projectpath` 的值；
**一律不打印整条 `CommandLine`**，也不靠"黑名单打码"兜底（黑名单永远列不全，这次漏的就是名单外的参数）。
要从命令行里拿 `-projectpath`，用**白名单提取**（正则只抽这一个参数的值），其余部分丢弃、不进任何输出与日志。
同理适用于 `ps -ef` / `wmic process` / `tasklist /v` 等所有会带出命令行或窗口标题的工具。
