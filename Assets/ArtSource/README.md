# 首轮美术制作记录

本轮为《十二玉楼长生经》的主菜单与角色选择准备手绘图像。菜单使用大都会艺术博物馆公共领域馆藏画作；农家、行旅、商家三套角色三视图已于 2026-09-27 经所有者自有 grok2api 网关生成并接入工程。提示词保存在仓库，密钥只在内存/临时文件中使用、不落仓库。

## 视觉约定

- 时代基调：元末明初的普通人生活；旧布、草鞋、竹篓、土墙与石路。玉楼仅作为远山中的朦胧伏笔。
- 画法：有纸张纹理的水墨淡彩与细线手绘，低饱和青绿、赭石、暖灰，暮色灯火。
- 菜单：当前馆藏画作呈现山村与远山；原定山村、古道、玉楼伏笔结合的完整构图保留在提示词（`prompts/menu-background-v1.txt`）中，后续需要时再制作。
- 角色：农家、行旅、商家三套平民外观 × 男/女 × 每性别两款发型（男：束发/裹巾；女：挽髻/双髻），共 12 组三视图，不据此承诺玩法加成或剧情身份；左视图运行时镜像右视图，首轮不是行走动画。改提示词必须保留 v1 模板的头部指令（`Use case` / `Asset type`），只替换 Subject 行的人物短语，否则上游会掉进写实照片模式。
- 物品与场景物件：宝箱、装备、物品图标按统一水墨淡彩模板单件生成（见 `PROVENANCE.md` 提示词模板），象牙底色与界面展示卡一致。
- 本轮角色图采用统一纯色背景作展示卡；不把带底色图冒充透明精灵。后续地图中角色的动作帧、碰撞和正式动画单独制作。

## 目录

- `prompts/`：最终提交给图像模型的完整提示词（v1 版）。
- `output/imagegen/`：生成过程中的临时结果（Git 忽略）。确认采用的原图复制到 `Assets/ArtSource/originals/` 并随仓库保存。
- `originals/`：选定采用的整张原图（1280×720 三联画，按 `{组合名}-turnaround-v1.png` 命名）。
- `GameClient/TwelveJade/Assets/Resources/Art/`：供 Unity 使用的角色三视图（`{id}-{gender}-{style}-{view}.png`）与菜单背景。
- `GameClient/TwelveJade/Assets/Resources/Art/Items/`：物品图标（宝箱、装备、消耗品等）。
- `PROVENANCE.md`：来源、生成参数、加工步骤和授权证据状态。

## 工具流程

实际生图渠道（2026-09-27 起生效）：项目所有者本人运维的 grok2api 网关（本机 `D:\work\amaze\DDyu`，`127.0.0.1:8000`，OpenAI 兼容接口）。经网关 `/v1/models` 选用 `grok-imagine-image`（quality 档），`POST /v1/images/generations`，参数 `n=1, aspect_ratio=16:9, response_format=b64_json`。客户端密钥从网关本地数据库加密字段解密取得，仅在内存/临时文件中使用，不写入仓库、提示词或日志。lite 档（`grok-imagine-image-lite`）实测会忽略提示词内容且上游偶发 502，弃用。

GeiliAPI 渠道（2026-09-26 的原计划）搁置：该密钥分组不含生图模型（`MODEL_NOT_AVAILABLE`），存档见 `PROVENANCE.md` 验收记录。

生成后检查时代服饰、图中文字、肢体完整性、角色朝向和可裁切性；任何无法验证的质量或授权问题记录在 `PROVENANCE.md`，不标记为已通过。角色图按画面三等分横列裁切为正面/右视/背面三张竖版视图；背景图将中心裁切到 16:9。
