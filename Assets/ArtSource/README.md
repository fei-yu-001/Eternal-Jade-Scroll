# 首轮美术制作记录

本轮为《十二玉楼长生经》的主菜单与角色选择准备手绘图像。当前菜单使用大都会艺术博物馆公共领域馆藏画作，三套角色画稿尚未生成。项目所有者已授权调用 GeiliAPI 图像服务；提示词保存在仓库，密钥只从本机环境读取。

## 视觉约定

- 时代基调：元末明初的普通人生活；旧布、草鞋、竹篓、土墙与石路。玉楼仅作为远山中的朦胧伏笔。
- 画法：有纸张纹理的水墨淡彩与细线手绘，低饱和青绿、赭石、暖灰，暮色灯火。
- 菜单：当前馆藏画作呈现山村与远山；原定山村、古道、玉楼伏笔结合的完整构图保留在提示词中，待图像服务权限具备后再制作。
- 角色：农家、行旅、商家三套平民外观，不据此承诺玩法加成或剧情身份。采用一致比例、服装细节与视角制作前、右、后视图；左视图可镜像右视图，首轮不是行走动画。
- 本轮角色图采用统一纯色背景作展示卡；不把带底色图冒充透明精灵。后续地图中角色的动作帧、碰撞和正式动画单独制作。

## 目录

- `prompts/`：最终提交给图像模型的完整提示词。
- `output/imagegen/`：未来放置生成过程中的临时结果（Git 忽略）。确认采用的原图复制到 `Assets/ArtSource/originals/` 并随仓库保存。
- `GameClient/TwelveJade/Assets/Resources/Art/`：供 Unity 使用的背景及未来角色展示图。
- `PROVENANCE.md`：来源、生成参数、加工步骤和授权证据状态。

## 工具流程

使用 Codex `imagegen` 技能随附的 `scripts/image_gen.py`，不修改该脚本。通过环境变量 `OPENAI_BASE_URL=https://image-direct.geiliapi.com/v1` 指定用户授权的服务；`OPENAI_API_KEY` 从本机 `GEILI_API_KEY` 读取，不写入仓库、提示词或日志。

GeiliAPI 文档在 2026-09-26 的约束：`gpt-image-2` 的 low 档使用 1K 密钥组，允许 `1536x1024`；medium/high 需要 2K4K 密钥组。当前密钥调用返回 `MODEL_NOT_AVAILABLE`，等待用户启用图像分组。之后先以 low 档生成一张画稿验证服务和画风，再生成三套角色。该模型在此 CLI 不提供透明背景参数。

参考接口文档：<https://sub.geiliapi.com/docs/gpt-image.llm.txt>。

使用参数：`generate --model gpt-image-2 --quality low --size 1536x1024 --no-augment --prompt-file <提示词> --out <原图路径>`。背景图将中心裁切到 16:9，角色图将按画面中的三列裁切为独立视图。

每张图完成后检查时代服饰、图中文字、肢体完整性、角色朝向和可裁切性。任何无法验证的质量或授权问题记录在来源文档中，不标记为已通过。
